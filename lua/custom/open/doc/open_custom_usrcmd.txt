1. INTRODUCTION                                         *open-custom-intro*

custom.open provides a single :Open <target> command that dispatches text from
the cursor position or visual selection to a handler (browser, file manager,
text editor, or a Neovim split/tab).

Design goals:
  • Consistent with :Insert and :Format (subcommand-style interface)
  • Cross-platform (Windows, macOS, Linux, WSL)
  • Tab-completion for all registered targets
  • Extensible via a simple handler registration API

==============================================================================
2. INSTALLATION                                   *open-custom-installation*

Add to your Neovim configuration (e.g. custom/init.lua):
>lua
    require("custom.open").setup()
<

With options:
>lua
    require("custom.open").setup({
      default_handler = "browser",  -- run when :Open is called with no args
    })
<

==============================================================================
3. USAGE                                                *open-custom-usage*

Syntax: ~
>vim
    :Open <target>
<

Tab-completion is available: ~
>vim
    :Open <Tab>
    " → browser, chrome, chromium, edge, editor, filemanager,
    "   firefox, notepad, safari, split, tab, vsplit
<

Normal mode: ~
    The WORD under the cursor (the largest non-whitespace run) is used.

Visual / visual-line mode: ~
    Type :Open after a visual selection; the selected text is used.

    Note: `:` exits visual mode, but Neovim preserves the '< and '> marks,
    which custom.open reads to reconstruct the selection.

4. TARGETS                                            *open-custom-targets*

------------------------------------------------------------------------------
4.1 Browser targets                                    *open-custom-browser*
                                                         *:Open-browser*

    browser     System default browser
    chrome      Google Chrome (or Chromium on Linux if Chrome absent)
    chromium    Chromium
    firefox     Mozilla Firefox
    edge        Microsoft Edge
    safari      Safari (macOS only; warns on other platforms)

Syntax: ~
>vim
    :Open browser
    :Open chrome
    :Open firefox
    :Open edge
    :Open safari
<

URL handling: ~
    • Text that already looks like a URL is passed through unchanged.
    • Text starting with "www." gets "https://" prepended.
    • All other text is treated as a search query (Google).
    • Local path text is opened via the file:// scheme.

Examples: ~
>vim
    " Cursor on: https://neovim.io
    :Open browser       → opens https://neovim.io in the default browser

    " Cursor on: www.lua.org
    :Open chrome        → opens https://www.lua.org in Chrome

    " Cursor on: pcall
    :Open browser       → opens Google search for "pcall"
<

Platform notes: ~
    Windows     cmd.exe /C start <browser-token> <url>
    WSL         wslview (if available), then cmd.exe start
    macOS       open / open -a <AppName>
    Linux       executable found on PATH from a priority list

------------------------------------------------------------------------------
4.2 filemanager                                   *open-custom-filemanager*
                                                    *:Open-filemanager*

Open a filesystem path in the platform's GUI file manager.

Syntax: ~
>vim
    :Open filemanager
<

Examples: ~
>vim
    " Cursor on: /home/alice/projects
    :Open filemanager   → opens Nautilus / Finder / Explorer at that path

    " Cursor on: ~/Downloads
    :Open filemanager   → expands ~ and opens the directory
<

Platform notes: ~
    Windows     explorer.exe <path>
    WSL         wslpath -w converts path, then explorer.exe
    macOS       open <dir> or open -R <file>  (reveals in Finder)
    Linux       xdg-open, nautilus, thunar, nemo, dolphin, pcmanfm …

URL text is rejected with a warning.

------------------------------------------------------------------------------
4.3 notepad / editor                                   *open-custom-notepad*
                                                         *:Open-notepad*
                                                          *:Open-editor*

Write the context text to a temporary .txt file and open it in the platform's
GUI text editor.  "editor" is an alias for "notepad".

Syntax: ~
>vim
    :Open notepad
    :Open editor
<

Examples: ~
>vim
    " Visual selection: multi-line log snippet
    :Open notepad   → writes to /tmp/nvimXXXX.txt, opens in Notepad / TextEdit

    " Cursor on a long URL
    :Open notepad   → copies URL to a temp file for inspection / editing
<

Platform notes: ~
    Windows / WSL   notepad.exe <tmpfile>
    macOS           open -e <tmpfile>  (TextEdit)
    Linux           xdg-open, gedit, kate, mousepad, leafpad, pluma, xed

The temporary file is not deleted automatically.

------------------------------------------------------------------------------
4.4 Neovim-internal targets                              *open-custom-nvim*
                                                          *:Open-split*
                                                         *:Open-vsplit*
                                                            *:Open-tab*

Open a local file inside the current Neovim session.

Syntax: ~
>vim
    :Open split     " horizontal split
    :Open vsplit    " vertical split
    :Open tab       " new tab
<

Examples: ~
>vim
    " Cursor on: lua/custom/insert/init.lua
    :Open split     → :split lua/custom/insert/init.lua

    " Cursor on: ~/notes/todo.md
    :Open tab       → :tabedit ~/notes/todo.md
<

Requirements: ~
    • Text must resolve to an existing file or directory.
    • URL text is rejected.

==============================================================================
5. CONTEXT EXTRACTION                                 *open-custom-context*

When :Open <target> is invoked, custom.open builds a context object:

    text     The raw text string
    is_url   Boolean — true when text matches http/https/ftp/www heuristic
    is_path  Boolean — true when text matches a path pattern or exists on disk

Extraction priority: ~
    1. Visual selection (via '< and '> marks) if non-empty
    2. WORD under cursor (<cWORD>)

The context is passed to the handler's run() function without modification.
Handlers are responsible for normalising the text (e.g. prepending https://).

6. CONFIGURATION                                       *open-custom-config*

>lua
    require("custom.open").setup({
      -- Run this handler when :Open is called with no arguments.
      -- nil (default) shows the usage / available-targets message.
      default_handler = nil,
    })
<

7. EXTENDING WITH CUSTOM HANDLERS                      *open-custom-extend*

Register a custom handler before or after setup():
>lua
    local registry = require("custom.open.registry")

    registry.register({
      key  = "vscode",
      desc = "Open file in Visual Studio Code",
      run  = function(ctx)
        if ctx.is_url then
          -- skip
          return false
        end
        local path = vim.fn.expand(ctx.text)
        vim.system({ "code", path }, { detach = true }, nil)
        return true
      end,
    })
<

Handler contract: ~
    key   string        Unique completion key (must be non-empty)
    desc  string        One-line description shown in :Open (no args)
    run   fun(ctx) → boolean
                        Receives Custom.Open.Context, returns true on success

8. KEYMAPS                                            *open-custom-keymaps*

Suggested mappings (not set automatically):
>lua
    local map = vim.keymap.set

    -- Normal mode: open link/path under cursor in default browser
    map("n", "<leader>ob", "<Cmd>Open browser<CR>",      { desc = "Open: browser" })

    -- Normal mode: open path in file manager
    map("n", "<leader>of", "<Cmd>Open filemanager<CR>",  { desc = "Open: filemanager" })

    -- Normal mode: open text in default editor
    map("n", "<leader>on", "<Cmd>Open notepad<CR>",      { desc = "Open: notepad" })

    -- Normal mode: open file in split
    map("n", "<leader>os", "<Cmd>Open split<CR>",        { desc = "Open: split" })

    -- Visual mode: open selection in browser
    map("x", "<leader>ob", "<Cmd>Open browser<CR>",      { desc = "Open selection: browser" })
<

9. LUA API                                              *open-custom-api*

Main module ~
    require("custom.open")

    .setup(opts)                                        *open.setup()*
        Initialize the module and register the :Open command.

        Parameters: ~
            {opts}  (Custom.Open.Config|nil)
                    • default_handler  string|nil

        Returns: ~
            nil

Registry ~
    require("custom.open.registry")

    .register(handler)                              *open.registry.register()*
        Register a new handler (or overwrite with warning).

        Parameters: ~
            {handler}  Custom.Open.Handler

        Returns: ~
            boolean

    .get(key)                                           *open.registry.get()*
        Look up a handler by key.

        Returns: ~
            Custom.Open.Handler|nil

    .list_keys()                                  *open.registry.list_keys()*
        Return sorted list of registered keys.

        Returns: ~
            string[]

Context ~
    require("custom.open.context")

    .build()                                         *open.context.build()*
        Extract context from current editor state.

        Returns: ~
            Custom.Open.Context|nil, string|nil error_message

Platform ~
    require("custom.open.platform")

    .get()                                            *open.platform.get()*
        Return cached platform descriptor.

        Returns: ~
            Custom.Open.Platform

10. TROUBLESHOOTING                           *open-custom-troubleshooting*

Q: "No text found under cursor or in selection" ~
A: In normal mode, the WORD at the cursor must be non-empty.
   In visual mode, make sure you selected text before running :Open.

Q: "Unknown target" error ~
A: Run :Open (no args) to see the available targets.
   Tab-complete with :Open <Tab> to browse them interactively.

Q: Browser does not open on Linux ~
A: Ensure xdg-open or the specific browser executable is on PATH.
   Check: :!which xdg-open

Q: filemanager fails in WSL ~
A: Requires wslpath (part of WSL2).  Verify with: !wslpath -w /

Q: notepad handler opens a blank file on macOS ~
A: TextEdit opens the file asynchronously; allow a moment for it to appear.

Q: Safari warns "only available on macOS" on Linux/Windows ~
A: Expected behaviour.  Use :Open browser or :Open chrome instead.
