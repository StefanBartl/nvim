1. INTRODUCTION                                         *find_config-introduction*

find_config is a cross-platform module for searching files and content within
the Neovim configuration directory using pluggable search engines (fzf-lua
or Telescope).

Key features:
  - Platform-agnostic (Linux, macOS, Windows, WSL)
  - Pluggable engine architecture
  - Configurable keymaps and commands
  - Case-insensitive fuzzy matching by default

==============================================================================
2. FEATURES                                                 *find_config-features*

  - Pluggable Engines        fzf-lua or Telescope support
  - Cross-Platform           Works on all Neovim platforms
  - Configurable Keymaps     Customize leader keys and suffixes
  - Configurable Commands    Custom command names
  - Engine Options           Direct access to engine-specific APIs
  - Fuzzy Matching           Case-insensitive search by default
  - Live Grep                Interactive real-time config search

==============================================================================
3. SETUP                                                       *find_config-setup*

Minimal setup with defaults:
>
    require("custom.find_config").setup()
<

This enables:
  - Default engine: fzf-lua
  - Keymaps: <leader>fc (find), <leader>gc (grep)
  - Commands: :FindConfig, :GrepConfig

==============================================================================
4. CONFIGURATION                                       *find_config-configuration*

4.1 BASIC OPTIONS                                  *find_config-config-basic*

Engine Selection~
>
    require("custom.find_config").setup({
      engine = "fzf",        -- "fzf" or "telescope"
    })
<

4.2 KEYMAP CONFIGURATION                          *find_config-config-keymaps*

Full keymap customization:
>
    require("custom.find_config").setup({
      keymaps = {
        enable = true,           -- Enable keymaps
        prefix = "<leader>",     -- Leader prefix
        find = "cf",             -- <leader>cf for Find
        grep = "cg",             -- <leader>cg for Grep
      },
    })
<

Disable keymaps:
>
    require("custom.find_config").setup({
      keymaps = { enable = false },
    })
<

4.3 USER COMMAND CONFIGURATION                  *find_config-config-usercmds*

Custom command names:
>
    require("custom.find_config").setup({
      usercmds = {
        enable = true,
        find = "ConfigFind",     -- :ConfigFind
        grep = "ConfigGrep",     -- :ConfigGrep
      },
    })
<

Disable user commands:
>
    require("custom.find_config").setup({
      usercmds = { enable = false },
    })
<

4.4 COMPLETE EXAMPLE                              *find_config-config-example*
>
    require("custom.find_config").setup({
      engine = "telescope",
      keymaps = {
        enable = true,
        prefix = "<leader>",
        find = "nf",  -- <leader>nf
        grep = "ng",  -- <leader>ng
      },
      usercmds = {
        enable = true,
        find = "NvimFind",
        grep = "NvimGrep",
      },
    })
<

==============================================================================
5. USAGE                                                       *find_config-usage*

5.1 KEYMAPS                                              *find_config-keymaps*

Default keymaps (after setup):

    <leader>fc    Find files in Neovim config
    <leader>gc    Live grep in Neovim config

Behavior:
  - Find: Opens fuzzy file picker in config directory
  - Grep: Opens interactive live grep search

5.2 USER COMMANDS                                      *find_config-commands*

    :FindConfig [query]      File search with optional initial query
    :GrepConfig [query]      Live grep with optional initial query

Examples:
>
    :FindConfig init
    :GrepConfig keymap
<

5.3 PROGRAMMATIC API                                       *find_config-api*

Direct API usage in custom code:
>
    local find_config = require("custom.find_config")

    -- File search
    find_config.find_in_config()

    -- Live grep
    find_config.grep_in_config()

    -- With engine-specific options
    find_config.find_in_config({
      prompt_title = "Custom Title",  -- Telescope
    })

    find_config.grep_in_config({
      fzf_opts = { ["--exact"] = "" },  -- fzf-lua
    })
<

6. ENGINES                                                   *find_config-engines*

6.1 FZF-LUA                                            *find_config-engine-fzf*

Advantages:
  - Extremely fast
  - Low memory footprint
  - Native Lua implementation
  - Flexible fzf syntax

Engine-specific options:
>
    find_config.find_in_config({
      prompt = "Custom Prompt❯ ",
      fzf_opts = {
        ["-i"] = "",           -- case-insensitive (default)
        ["--exact"] = "",      -- exact match
        ["--no-sort"] = "",    -- disable sorting
      },
    })
<

Documentation: :help fzf-lua

6.2 TELESCOPE                                    *find_config-engine-telescope*

Advantages:
  - Rich UI with preview
  - Extensive extension ecosystem
  - Native integration with many plugins
  - Configurable layouts

Engine-specific options:
>
    find_config.find_in_config({
      prompt_title = "Config Files",
      layout_strategy = "vertical",
      layout_config = {
        width = 0.9,
        height = 0.9,
      },
    })

    find_config.grep_in_config({
      additional_args = function()
        return { "--case-sensitive" }
      end,
    })
<

Documentation: :help telescope.builtin

7. API REFERENCE                                        *find_config-api-reference*

7.1 SETUP FUNCTION                                        *find_config.setup()*

    require("custom.find_config").setup({opts})

Parameters:~
    {opts}    Table with configuration options:
              - engine: "fzf" | "telescope" (default: "fzf")
              - keymaps: { enable, prefix, find, grep }
              - usercmds: { enable, find, grep }

Returns:~
    nil

7.2 FIND FUNCTION                                  *find_config.find_in_config()*

    find_config.find_in_config({opts})

Search for files in Neovim config directory.

Parameters:~
    {opts}    Engine-specific options table (optional)

Returns:~
    nil

7.3 GREP FUNCTION                                  *find_config.grep_in_config()*

    find_config.grep_in_config({opts})

Live grep search in Neovim config directory.

Parameters:~
    {opts}    Engine-specific options table (optional)

Returns:~
    nil

8. TROUBLESHOOTING                                 *find_config-troubleshooting*

8.1 ENGINE NOT FOUND

Error: "fzf-lua not found or missing 'files' function"

Solution:
    Install the required engine:
>
    -- For fzf-lua
    use { 'ibhagwan/fzf-lua' }

    -- For Telescope
    use { 'nvim-telescope/telescope.nvim' }
<

8.2 SETUP NOT CALLED

Error: "Engine not initialized. Call setup() first."

Solution:
    Call setup() before using find_in_config or grep_in_config:
>
    require("custom.find_config").setup()
<

8.3 KEYMAPS NOT WORKING

Verify:
    1. setup() was called with keymaps.enable = true
    2. No conflicting keymaps in your config
    3. Check with :nmap <leader>fc to see current mapping

8.4 CONFIG DIRECTORY NOT FOUND

Verify:
    :echo stdpath('config')

Should return your Neovim config directory.
If empty, check $MYVIMRC or reinstall Neovim.
