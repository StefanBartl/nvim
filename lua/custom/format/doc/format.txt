1. INTRODUCTION                                                 *format-intro*

The custom.format module provides a unified interface for various text
formatting operations in Neovim. All operations are accessible through the
|:Format| command with intelligent tab completion.

Features:
• Column alignment with configurable fill characters
• Markdown table formatting with per-role and per-column alignment control
• Text reflow to specified width
• Line filtering based on patterns
• Token enumeration in visual selections (any filetype)
• Quick buffer clearing

==============================================================================
2. INSTALLATION                                         *format-installation*

Add to your Neovim configuration:
>lua
    require("custom.format").setup({
      enable_legacy_commands = true,
      default_subcommand = nil,
    })
<

==============================================================================
3. USAGE                                                        *format-usage*

General syntax:
>vim
    :Format <subcommand> [arguments...]
<

Tab completion is available for subcommand names and their arguments.
Without arguments, :Format shows available subcommands.

==============================================================================
4. COMMANDS                                                  *format-commands*

------------------------------------------------------------------------------
4.1 :Format column                                            *format-column*
                                                       *:Format-column*

Align visually selected character(s) to a target column.

Syntax: ~
>vim
    :Format column [<target_col> [fill_char]]
<

Without arguments, prompts interactively.

Modes: ~
    v       Visual mode: single line, single character
    <C-v>   Visual block: multiple lines, same column position

Examples: ~
>vim
    :Format column
    :Format column 40
    :Format column 60 _
<

------------------------------------------------------------------------------
4.2 :Format table                                              *format-table*
                                                        *:Format-table*

Format one or more Markdown tables.

Syntax: ~
>vim
    :Format table [ALIGN] [header=ALIGN] [cell=ALIGN] [skip=COLS] [scope=SCOPE]
<

See |format-api-table| for the full option reference.

Examples: ~
>vim
    :Format table
    :Format table left
    :Format table center left
    :Format table header=center cell=left skip=Beschreibung scope=buffer
<

------------------------------------------------------------------------------
4.3 :Format textwidth                                      *format-textwidth*
                                                     *:Format-textwidth*

Reflow text to specified width.

Syntax: ~
>vim
    :Format textwidth <N|max>
<

Examples: ~
>vim
    :Format textwidth 80
    :Format textwidth max
<

------------------------------------------------------------------------------
4.4 :Format filter                                            *format-filter*
                                                       *:Format-filter*

Filter buffer lines based on patterns.

Syntax: ~
>vim
    :Format filter [--remove | -r] <pattern> [<pattern>...]
<

Examples: ~
>vim
    :Format filter foo
    :Format filter --remove TODO
    :Format filter foo { "bar", "baz" }
<

------------------------------------------------------------------------------
4.5 :Format clear                                              *format-clear*
                                                        *:Format-clear*

Clear all buffer content.

>vim
    :Format clear
<

Use |u| to undo.

4.6 :Format enum                                               *format-enum*
                                                        *:Format-enum*

Enumerate whitespace-separated tokens in the current visual selection and
replace the selected region with the numbered result.

Works in ANY filetype – no Markdown requirement.

Syntax: ~
>vim
    :Format enum [STYLE] [style=STYLE] [sep=SEP] [start=N] [inline=true|false]
<

Arguments: ~

    STYLE (bare positional)                              *format-enum-style*
        Shorthand for style=STYLE. One of:
            decimal   1. 2. 3. …  (default)
            alpha     a. b. c. …
            ALPHA     A. B. C. …
            roman     i. ii. iii. …
            ROMAN     I. II. III. …

    style=STYLE
        Same as bare STYLE; key=value form, takes precedence.

    sep=SEP                                              *format-enum-sep*
        String placed between the counter and the token text.
        Default: ". "  (period + space)
        Examples: sep=)   → "1) foo"
                  sep=":  "  → "1:  foo"
        Note: the value is used verbatim; add a trailing space inside the
        quotes if you want one: sep=") "

    start=N                                              *format-enum-start*
        Counter value for the first token. Default: 1.
        Useful for continuing an existing list: start=4 → "4. foo 5. bar".

    inline=true|false                                    *format-enum-inline*
        true  → all labelled tokens are joined on ONE output line.
        false → each labelled token goes on its OWN output line.
        When omitted, the behaviour is determined automatically:
          • single-line selection → inline (true)
          • multi-line selection  → one per line (false)

Behaviour: ~
    • Every whitespace-separated token across all selected lines is collected.
    • Empty lines inside the selection are skipped (contribute no tokens).
    • The leading indentation of the first selected line is preserved on the
      first output line.
    • The selected region is replaced in-place; surrounding lines are untouched.

Tab completion: ~
    Styles, key=value forms, and common sep / start values are all
    offered by <Tab> during command-line completion.

Examples: ~
>vim
    " Select 'Eins Zweite Drita' on one line, then run:
    :Format enum
    " → 1. Eins 2. Zweite 3. Drita

    " Alpha style
    :Format enum alpha
    " → a. Eins b. Zweite c. Drita

    " Roman numerals, custom separator
    :Format enum roman sep=)
    " → i) Eins ii) Zweite iii) Drita

    " Continue a list at 4
    :Format enum start=4
    " → 4. Eins 5. Zweite 6. Drita

    " Force one token per line
    :Format enum inline=false
    " → 1. Eins
    "   2. Zweite
    "   3. Drita

    " Combined
    :Format enum ROMAN sep=": " start=2 inline=false
    " → II: Eins
    "   III: Zweite
    "   IV: Drita
<

Lua API: ~
>lua
    local core = require("custom.format.enum_lines.core")

    -- Operate on the visual selection in the current buffer:
    core.enum_selection({ style = "alpha", sep = ") " })

    -- Operate on an explicit line range:
    local result = core.enum_range(0, 3, 7, { style = "roman", inline = false })
    -- result.ok    → boolean
    -- result.lines → string[]  (new buffer lines)
    -- result.count → integer   (number of tokens enumerated)
    -- result.err   → string|nil
<

See also: ~
    custom/format/enum_lines/core.lua   – full implementation
    custom/format/enum_lines/@types.lua – type annotations

6. KEYMAPS                                                    *format-keymaps*

The module sets no global keymaps by default. Suggested mappings:
>lua
    -- Enumerate selection
    vim.keymap.set("x", "<leader>ae", "<Cmd>Format enum<CR>", {
      desc = "Enumerate selected tokens"
    })

    -- Column alignment
    vim.keymap.set("x", "<leader>ac", "<Cmd>Format column<CR>", {
      desc = "Align character to column"
    })

    -- Table formatting
    vim.keymap.set("n", "<leader>ft", "<Cmd>Format table<CR>", {
      desc = "Format table at cursor"
    })
<

7. LUA API                                                       *format-api*

Main module: ~
    require("custom.format").setup(opts)                     *format.setup()*

------------------------------------------------------------------------------
                                                            *format-api-table*
Format Table: ~
    require("custom.format.table")

    .format_table_at_cursor(bufnr, opts)
    .format_tables_in_buffer(bufnr, opts)
    .format_tables_in_scope(opts)

    opts keys: header_align, entry_align, col_overrides, scope

------------------------------------------------------------------------------
                                                             *format-api-enum*
Enum Lines: ~
    require("custom.format.enum_lines.core")

    .enum_selection(opts)                         *format.enum_selection()*
        Enumerate the visually selected region in the current buffer.

        Parameters: ~
            {opts}  (Custom.Format.EnumLines.Opts|nil)

        Returns: nil

    .enum_range(bufnr, start_line, end_line, opts)  *format.enum_range()*
        Enumerate a specific line range (programmatic use).

        Parameters: ~
            {bufnr}       (integer)   Buffer number (0 = current)
            {start_line}  (integer)   First line, 1-based
            {end_line}    (integer)   Last line, 1-based inclusive
            {opts}        (Custom.Format.EnumLines.Opts|nil)

        Returns: Custom.Format.EnumLines.Result
            • ok     (boolean)
            • lines  (string[])  – new buffer lines
            • count  (integer)   – number of tokens enumerated
            • err    (string|nil)

    .enumerate(lines, opts)                            *format.enumerate()*
        Pure function: enumerate tokens from a string[] without side-effects.
        Useful for testing or preview.

        Parameters: ~
            {lines}  (string[])
            {opts}   (Custom.Format.EnumLines.Opts|nil)

        Returns: Custom.Format.EnumLines.Result

Type definition: ~
>lua
    ---@class Custom.Format.EnumLines.Opts
    ---@field style?   "decimal"|"alpha"|"ALPHA"|"roman"|"ROMAN"
    ---@field sep?     string    -- default ". "
    ---@field start?   integer   -- default 1
    ---@field inline?  boolean   -- nil = auto
<

9. EXAMPLES                                                  *format-examples*

>

    Output:  markdown 1. Eins 2. Zweite 3. Drita
<

Enum – alpha style: ~
>
    Input:   foo bar baz

    Output:  a. foo b. bar c. baz

Enum – one per line with roman numerals: ~
>
    Input (3 lines visually selected):
      Step one
      Step two
      Step three
    Command: :Format enum roman inline=false

      i. Step one
      ii. Step two
      iii. Step three

>
    Input:   delta epsilon
    Command: :Format enum start=4
    Output:  4. delta 5. epsilon
<

>
    Input:   key=value    (= selected)
    Command: :Format column 40 _
    Output:  key_________________________________________=value
<

Table Formatting: ~
>markdown
    Before:
    | Name | Age | City |
    |---|---|---|
    | Alice | 30 | NYC |

    :Format table center left

    After:
    |  Name  | Age | City |
    |--------|-----|------|
    | Alice  | 30  | NYC  |

10. TROUBLESHOOTING                                  *format-troubleshooting*

Q: `:Format enum` reports "No tokens found" ~
A: The visual selection must contain at least one non-whitespace character.
   Ensure you are in Visual mode (v / V / <C-v>) before running the command.

Q: All tokens appear on one line but I want one per line ~
A: Add inline=false:
>vim
    :Format enum inline=false
<

Q: I want a custom separator without a trailing space ~
A: Pass sep= with the exact string you want, e.g. sep=): produces "1)token".
   Add the space inside the value: sep=") " to get "1) token".

Q: "Unknown subcommand" error ~
A: Check available subcommands with :Format (no arguments).
   Verify setup was called: require("custom.format").setup()

Q: Table not detected ~
A: Ensure cursor is inside the table, which needs header + separator + data row,
   with the separator on line 2 directly after the header.

Q: Completion not working ~
A: Verify setup() was called in your configuration:
>lua
    require("custom.format").setup()
<
