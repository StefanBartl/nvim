*custom-markdown.txt*   Minimal Markdown folding & navigation
==============================================================================
INTRODUCTION                                                   *custom-markdown*

A tiny, safe set of Markdown helpers for Neovim:

  • fast foldexpr for ATX H1..H6 and Setext H2
  • heading navigation and level shifting (ATX)
  • selection wrap (**)
  • markerless table-of-contents (TOC)

Single source of truth for keymaps: |custom-markdown-keymaps|.
A lightweight shim exists: |custom-markdown-shim|.

==============================================================================
SETUP                                                        *custom-markdown-setup*

>lua
  require("custom.markdown").setup({
    map_double_asterisk   = true,
    keep_inner_selection  = true,
    protect_h1            = true,
    enable_keymaps        = true,
    ft_only               = true,   -- buffer-local maps on FileType=markdown
    use_zf_override       = false,  -- keep native 'zf'
    enable_autocmds       = false,  -- reserved for your own UI hooks
  })

TIP: If you prefer a FileType-oriented entrypoint, see |custom-markdown-shim|.

==============================================================================
OPTIONS                                                     *custom-markdown-options*

map_double_asterisk (bool)  Visual "**" mapping. Default: true
keep_inner_selection (bool) Reselect inner text after wrapping. Default: true
protect_h1 (bool)           Never demote below H1 when shifting. Default: true
enable_keymaps (bool)       Install unified keymaps. Default: true
ft_only (bool)              If true, keymaps are buffer-local on FileType=markdown.
                            If false, keymaps are installed once globally.
                            Default: false
use_zf_override (bool)      If true, map 'zf' to fold toggle. Default: false
enable_autocmds (bool)      For your own UI/FileType hooks (e.g. conceallevel).
                            Not required for keymaps. Default: false

Keymaps logic (independent of 'enable_autocmds'):
  • enable_keymaps=true,  ft_only=false → global maps (once)
  • enable_keymaps=true,  ft_only=true  → buffer-local maps on FileType=markdown
  • enable_keymaps=false                → no maps

==============================================================================
KEYMAPS                                                     *custom-markdown-keymaps*

By default (when |custom-markdown-options| enable_keymaps=true):

MODE  LHS               ACTION
----  ----------------  ---------------------------------------------
x     **                Toggle ** around visual selection
n     <localleader>f    Toggle fold under cursor & center
n     zu                Unfold all & center
n     zi                Fold previous heading & center
n     zk                Fold H2+ (keep H1 open)
n/v   mk                Previous heading (H2+)
n/v   mj                Next heading (H2+)
n     <leader>toc       Insert/refresh markerless TOC

To override native 'zf' (opt-in):
>lua
  require("custom.markdown").setup({ use_zf_override = true })

==============================================================================
FOLDING                                                     *custom-markdown-folding*

Use the module foldexpr for Markdown buffers:

>lua
  vim.api.nvim_create_autocmd("FileType", {
    pattern = { "markdown", "markdown.mdx", "mdx" },
    callback = function()
      vim.opt_local.foldmethod = "expr"
      vim.opt_local.foldexpr   = "v:lua.require'custom.markdown.core.fold'.foldexpr(v:lnum)"
      vim.opt_local.foldenable = true
      vim.opt_local.foldlevel  = 99
      vim.opt_local.foldlevelstart = 99
    end,
  })

Optional UX:
>lua
  vim.opt.foldnestmax = 6
  vim.opt.foldcolumn  = "1"

Helpers:
  *custom.markdown.core.fold.toggle_under_cursor()*
      Toggle fold at cursor and center the view (za → zz).

  *custom.markdown.core.fold.unfold_all_center()*
      Unfold everything and center (zR → zz).

  *custom.markdown.core.fold_prev.fold_prev_heading_then_center()*
      Fold the previous heading block, then center.

  *custom.markdown.core.fold_levels.fold_levels({2,3,4,5,6})*
      Keep only H2+ folded (example), leaving H1 open.

Notes:
  • ATX headings (# … ######) start folds at their level.
  • Setext H2 (---) is recognized as level-2 fold.
  • Fenced code is ignored for TOC; foldexpr remains line-based for speed.

==============================================================================
HEADINGS                                                   *custom-markdown-headings*

Navigation:
  *custom.markdown.core.headings.goto_prev_heading()*
      Jump to previous heading (H2+).

  *custom.markdown.core.headings.goto_next_heading()*
      Jump to next heading (H2+).

Shifting (ATX only):
  *custom.markdown.shift_increase()*
  *custom.markdown.shift_decrease()*
      Promote/demote ATX heading level. With |custom-markdown-options| protect_h1=true,
      H1 is never demoted below level 1.

Setext headings (===, ---) are not shifted; this is by design for clarity.

==============================================================================
SELECTION WRAP                                             *custom-markdown-wrap*

  *custom.markdown.core.wrap.toggle_visual_bold()*
      Wrap selection in `**` while in Visual mode.
      With keep_inner_selection=true the inner text is reselected after wrapping.

==============================================================================
TOC (MARKERLESS)                                           *custom-markdown-toc*

  *custom.markdown.core.toc.update_markdown_toc({header_line})*
      Insert/replace a markerless TOC block (default header: "## Table of content")
      right after the first H1 (or after front matter if present).

Behavior:
  • Skips fenced code blocks (``` or ~~~; language optional).
  • Anchors are GitHub-like and de-duplicated (foo, foo-2, ...).
  • Existing TOC block (starting with the header line) is replaced in-place.

Example:
>lua
  require("custom.markdown.core.toc").update_markdown_toc("## Table of content")

==============================================================================
HEALTH                                                     *custom-markdown-health*

Run:
>lua
  require("custom.markdown.ui.health").check()

Reports whether config and core modules load. Uses Neovim ≥0.10 health API
when available, falls back otherwise.

==============================================================================
SHIM                                                       *custom-markdown-shim*

The compatibility shim does not define its own keymaps. It forwards setup:

>lua
  require("mappings.markdown").setup({
    enable_keymaps = true,
    ft_only = true,   -- buffer-local maps on FileType=markdown
  })

Use this if you prefer configuring everything from a central "mappings" layer.

==============================================================================
NOTES / LIMITATIONS                                        *custom-markdown-notes*

  • Heading shift affects ATX headings only.
  • TOC ignores fenced code; anchors are GitHub-like with de-duplication.
  • 'enable_autocmds' is reserved for your own UI/FileType hooks (e.g., conceal),
    and does not influence keymap installation.
