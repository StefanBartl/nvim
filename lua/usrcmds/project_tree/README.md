# usrcmds.project_tree

Asynchronous project structure utilities for Neovim (Linux/macOS).
Generates a portable file tree, counts files, and copies the tree to the clipboard without blocking the UI.
Backed by `find`, `sed`, and `wc`; uses `vim.system` (Neovim ≥ 0.10) for async execution.

## Features

* Write a project file tree to a configurable output path (relative entries, sorted, excludes respected)
* Count project files quickly using external tools
* Copy the generated tree content to the system clipboard (uses `setreg("+", ...)`, falls back to `xclip`)
* Fully asynchronous; clear, typed API with callbacks
* Portable pipeline (no GNU `-printf` dependency)

## Requirements

* Neovim 0.10+ recommended (uses `vim.system` with `text=true`)
* POSIX shell tools available in PATH: `sh`, `find`, `sed`, `wc`
* Optional clipboard fallback: `xclip` (Linux). Primary path uses Neovim’s `+` register.

## Installation (Lazy.nvim)

```lua
{
  -- Place the module here: ~/.config/nvim/nvim/usrcmds/project_tree
  dir = vim.fn.stdpath("config") .. "/nvim/usrcmds/project_tree",
  name = "project_tree",
  lazy = true,
  config = function()
    require("usrcmds.project_tree").setup({
      -- Optional configuration; shown with defaults:
      exclude_patterns = { "*/.git/*" },         -- shell globs excluded from the listing
      outdir = (os.getenv("XDG_STATE_HOME") and (os.getenv("XDG_STATE_HOME") .. "/nvim/project-tree"))
               or (os.getenv("HOME") .. "/.local/state/nvim/project-tree"),
      outfile_fmt = "%s-tree.txt",               -- %s is replaced by the project name
      notify_prefix = "[ProjectTree] ",
      use_system_clipboard = true,               -- try setreg("+", ...) first; fallback to xclip
    })
  end,
  cmd = { "ProjectTreeGet", "ProjectTreeCopyClipboard", "ProjectFilesCount" },
}
```

## Module path

* File: `nvim/usrcmds/project_tree/init.lua`
* Require: `require("usrcmds.project_tree")`

## Commands

* `:ProjectTreeGet`
  Writes the tree to the configured output file and reports the target path.

* `:ProjectTreeCopyClipboard`
  Copies the existing tree file to the system clipboard. Uses `setreg("+", ...)` first; if that fails and `xclip` exists, uses `xclip`.

* `:ProjectFilesCount`
  Counts files in the project (respects `exclude_patterns`) and reports the number.

## Configuration

Plain-text options and defaults

## Name                  Type        Default                                    Description

exclude_patterns      string[]    { "*/.git/*" }                              Shell globs to exclude
outdir                string      $XDG_STATE_HOME/nvim/project-tree or        Output directory for files
~/.local/state/nvim/project-tree
outfile_fmt           string      "%s-tree.txt"                               Output file name pattern
notify_prefix         string      "[ProjectTree] "                             Prefix for returned messages
use_system_clipboard  boolean     true                                        Use Neovim clipboard before xclip

Notes

* The project name used in `outfile_fmt` is the tail of the current working directory (`:pwd`).
* Output directory is ensured (`mkdir -p` semantics); warnings are emitted if it cannot be created.

## API

```lua
-- Load and configure once (idempotent)
local pt = require("usrcmds.project_tree")
pt.setup({
  exclude_patterns = { "*/.git/*", "*/node_modules/*", "*/.venv/*" },
  -- other keys as needed
})

-- Write the tree file; callback receives (success:boolean, message:string, outpath:string|nil)
pt.write_tree(function(ok, msg, outpath)
  -- handle result (notify, open file, etc.)
end)

-- Count files; callback receives (success:boolean, message:string, count:integer|nil)
pt.count_files(function(ok, msg, n)
  -- handle result
end)

-- Copy to clipboard; callback receives (success:boolean, message:string)
pt.copy_tree_to_clipboard(function(ok, msg)
  -- handle result
end)
```

## How it works

* The module resolves the current project as the current working directory plus its tail as the project name.
* The tree is generated by a portable pipeline:

  * `find <cwd> -type f [ -not -path "<glob>" ... ] -print | sed -e "s#^<cwd>/##" | sort`
* Counting is derived from the same listing: `... | wc -l`
* Clipboard:

  * Primary: read the generated file and `setreg("+", content)`
  * Fallback (Linux): `xclip -selection clipboard < <file>`

## Examples

* Create the tree, then open it in a new tab:

```lua
require("usrcmds.project_tree").write_tree(function(ok, msg, path)
  if ok and path then vim.cmd("tabedit " .. vim.fn.fnameescape(path)) end
  vim.notify(msg, ok and vim.log.levels.INFO or vim.log.levels.ERROR)
end)
```

* Count files excluding extra directories:

```lua
require("usrcmds.project_tree").setup({
  exclude_patterns = { "*/.git/*", "*/node_modules/*", "*/dist/*", "*/.venv/*", "*/target/*" },
})

require("usrcmds.project_tree").count_files(function(ok, msg, n)
  vim.notify(msg, ok and vim.log.levels.INFO or vim.log.levels.ERROR)
end)
```

* Copy the existing tree to the clipboard:

```lua
require("usrcmds.project_tree").copy_tree_to_clipboard(function(ok, msg)
  vim.notify(msg, ok and vim.log.levels.INFO or vim.log.levels.ERROR)
end)
```

## Portability and platform notes

* Linux and macOS supported. The pipeline uses `find`, `sed`, and `wc` available on both systems; GNU-specific `-printf` is intentionally avoided.
* `xclip` is Linux-specific and used only as a fallback. With a working clipboard provider in Neovim, `setreg("+", ...)` is sufficient.

## Design goals and guarantees

* Asynchronous, non-blocking operations using `vim.system` when available
* Clear separation of concerns: low-level functions return results; UI notifications live in the calling layer
* Robust error reporting and consistent callback signatures
* Minimal global state: only `M.opts` is stored; everything else is function-scoped

## Troubleshooting

## Problem                              Cause/Resolution

“tree file does not exist”           Run `:ProjectTreeGet` first, or check `outdir/outfile_fmt`
“cannot parse count”                 Inspect shell output; ensure `sed` and `wc` are available
No clipboard content                 Ensure Neovim clipboard provider is configured; `xclip` as fallback
Unexpected files included            Extend `exclude_patterns` with relevant globs
Wrong project name                   Check `:pwd` and directory naming; `outfile_fmt` uses the tail of `:pwd`

## Security and safety

* All dynamic shell inputs are escaped (`shellescape`).
* The tree file is written to an XDG-compliant state directory by default.
* Clipboard operations avoid arbitrary command execution by preferring Neovim’s `setreg`.
