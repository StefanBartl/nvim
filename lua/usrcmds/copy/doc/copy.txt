INTRODUCTION                                                *copy-introduction*

The `:Copy` command provides flexible path copying functionality with support
for relative/absolute paths, custom separators, and Neovim-specific workflows.

Key features:
- Relative paths to cwd, parent directories, or custom bases
- Absolute paths with customizable separators
- Neovim config-aware paths (|copy-nvim|)
- Lua module path generation (|copy-nvim-module|)
- Custom path separators for cross-platform compatibility

================================================================================
USAGE                                                              *copy-usage*

Basic syntax: >
    :Copy path [mode] [base] [target_type] [target_path] [sep <separator>]


All arguments are optional. Default behavior: >
    :Copy path

Copies the current file's path relative to cwd using `/` separator.

================================================================================
MODES                                                              *copy-modes*

*copy-relative*
Relative mode (default):
Calculates path relative to a base directory. >
    :Copy path relative


*copy-absolute*
Absolute mode:
Returns full absolute path. >
    :Copy path absolute


================================================================================
BASE SELECTION                                                      *copy-base*

When using relative mode, the base directory can be specified in three ways:

1. Current working directory (default): >
    :Copy path relative


2. Parent level (numeric):
   Specify how many parent directories up from the target file. >
    :Copy path relative 2

   Example:
   File: `C:/Users/name/AppData/Local/nvim/lua/ui/test.lua`
   Base: `C:/Users/name/AppData/Local/nvim` (2 levels up)
   Result: `lua/ui/test.lua`

3. Explicit path: >
    :Copy path relative /custom/base/path


================================================================================
TARGET TYPES                                                      *copy-target*

*copy-file*
File target (default):
Copies the file path. >
    :Copy path file


*copy-dir*
Directory target:
Copies the parent directory path. >
    :Copy path dir


Target path can be specified explicitly: >
    :Copy path relative file /path/to/other/file.lua


================================================================================
SEPARATORS                                                      *copy-separator*

*copy-sep*
Custom path separator:
Change the path separator character. >
    :Copy path sep .
    :Copy path separator \


Aliases: `sep` and `separator`

Examples: >
    :Copy path relative sep .

Result: `lua.ui.test.lua`
>
    :Copy path absolute sep \

Result: `C:\Users\name\nvim\lua\ui\test.lua`

================================================================================
SPECIAL MODES                                                      *copy-special*

*copy-nvim*
Neovim config mode:
Calculates path relative to |stdpath| `('config')`.
Only works for files inside Neovim config directory. >
    :Copy path nvim


Example:
File: `~/.config/nvim/lua/plugins/lsp.lua`
Result: `lua/plugins/lsp.lua`

If file is outside config directory, shows warning.

*copy-nvim-module*
Lua module mode:
Converts file path to Lua module path (dot-separated).
Only works for files in `lua/` directories. >
    :Copy path nvim_module


Examples:
File: `~/.config/nvim/lua/plugins/lsp.lua`
Result: `plugins.lsp`

File: `~/.config/nvim/lua/lib/notify/init.lua`
Result: `lib.notify`

If file is not in a `lua/` directory, shows warning.

================================================================================
EXAMPLES                                                        *copy-examples*

Basic examples: >
    :Copy path

Result: `lua/ui/test.lua` (relative to cwd)
>
    :Copy path absolute

Result: `C:/Users/name/nvim/lua/ui/test.lua`
>
    :Copy path relative 3 dir

Result: Directory path 3 levels up
>
    :Copy path relative /custom/base file

Result: Path relative to `/custom/base`

Neovim-specific: >
    :Copy path nvim

Result: `lua/plugins/telescope.lua` (relative to config)
>
    :Copy path nvim_module

Result: `plugins.telescope` (Lua module path)

Custom separators: >
    :Copy path nvim sep .

Result: `lua.plugins.telescope.lua`
>
    :Copy path absolute sep \

Result: `C:\Users\name\nvim\lua\plugins\telescope.lua`

Combined: >
    :Copy path relative 2 file /other/file.lua sep .

Result: Relative path with `.` separator

================================================================================
AUTOCOMPLETION                                                  *copy-completion*

The `:Copy` command provides intelligent autocompletion for all arguments.

Available completions:
- `path` - Main subcommand
- `absolute` - Absolute mode
- `relative` - Relative mode
- `nvim` - Neovim config mode
- `nvim_module` - Lua module mode
- `file` - File target
- `dir` - Directory target
- `sep` - Separator keyword
- `separator` - Separator alias
- `0-5` - Parent level shortcuts

Usage:
Start typing and press <Tab> to see available options.

================================================================================
FEATURES                                                        *copy-features*

- Cross-platform path normalization
- Intelligent base directory selection
- Custom separator support for any character
- Neovim config-aware functionality
- Lua module path generation
- Clipboard integration (|clipboard|)
- Extensible architecture for future modes

================================================================================
NOTES                                                              *copy-notes*

- All paths are normalized for consistent output
- The `nvim` mode only works inside |stdpath| `('config')`
- The `nvim_module` mode only works for files in `lua/` directories
- Custom separators apply to the entire path
- Arguments can be provided in any order (with sensible defaults)
