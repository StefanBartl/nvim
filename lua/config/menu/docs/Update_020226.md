## Änderungen

### 1. Neo-tree Menu Entries (`entries.lua`)

**Aktualisiert:** Vollständige Synchronisation mit allen `config.neotree.keymaps.filesystem.*` Modulen

**Neue/Aktualisierte Keymaps:**

#### Base Keymaps
- `q`: Close window
- `?`: Show help
- `<Esc>`: Clear search/filter/preview/quarantine
- `"`: Next source
- `!`: Previous source
- `R`: Refresh
- `C`: Close node
- `z`: Close all nodes
- `W`: Open with window picker
- `w`: Resize window (cycle)

#### Filter
- `f`: Filter on submit
- `F`: Fuzzy finder
- `<C-c>`: Clear filter

#### Commands
- `i`: Run command
- `tf`: Telescope find files
- `tg`: Telescope live grep

#### Files
- `<CR>`: Open / Expand node
- `<2-LeftMouse>`: Open node
- `<S-CR>`, `gb`: Open in background
- `sg`: Open vsplit
- `sv`: Open split
- `st`: Open new tab

#### Save
- `<C-s>`: Force-save last normal buffer
- `<M-s>`: Force-save node buffer

#### Preview
- `<Tab>`: Toggle preview
- `<C-b>`, `<C-f>`: Scroll preview
- `<PageUp>`, `<PageDown>`: Page scroll

#### Replace
- `O`: Open and replace buffer

#### Clipboard
- `c`: Copy marked/current to clipboard
- `x`: Cut marked/current to clipboard
- `p`: Paste from clipboard

#### Create
- `a`: Add file/folder
- `D`: Diff files
- `r`: Rename

#### Trash
- `d`: Delete (trash)
- `U`: Undo last trash
- `<leader>th`: Show trash history

#### Mark
- `m`: Mark/Unmark file
- `]m`: Mark all in directory
- `[m`: Unmark all in directory
- `<C-m>`: Clear all marks
- `<leader>ms`: Show marked nodes

#### Navigation
- `+`: Navigate into directory (set root)
- `-`: Navigate up one level

#### Path Operations
- `[a]`: Copy absolute path
- `]a]`: Copy base dir path
- `[f]`: Copy file list (absolute)
- `]f]`: Copy file list (relative)
- `[F]`: Copy folder list (absolute)
- `]F]`: Copy folder list (relative)

#### Info
- `I`: Show file/directory info
- `<leader>fm`: Open in file manager
- `<leader>sm`: Open with system app
- `rq`: Copy require() string

#### Search
- `gr`: Live grep (auto)
- `<leader>gt`: Live grep (telescope)
- `<leader>gf`: Live grep (fzf-lua)

### 2. Custom Menu (`custom_menu.lua`)

**Neue Einträge:**

#### Copy Operations
1. **Copy All (Buffer)** - `<C-a>`
   - Kopiert den gesamten Buffer-Inhalt in die Zwischenablage
   - Command: `%y+`

2. **Copy Marked/Selected** - `<C-c>`
   - Kopiert markierten/ausgewählten Text (Visual Mode)
   - Fallback: Kopiert gesamten Buffer wenn keine Auswahl
   - Smart: Erkennt automatisch Visual Selection

#### Delete Operations
1. **Delete Marked/Selected** - `dm`
   - Löscht markierten/ausgewählten Text (Visual Mode)
   - Warnung wenn keine Auswahl vorhanden

2. **Delete All (Clear Buffer)** - `da`
   - Löscht gesamten Buffer-Inhalt
   - Mit Bestätigungsdialog
   - Command: `%d`

3. **Delete File** - `df`
   - Löscht die aktuelle Datei vom Dateisystem
   - Mit Bestätigungsdialog
   - Schließt automatisch den Buffer nach Löschung
   - Icon: 🗑️

#### Tools
4. **Unicode Table** - `uni`
   - Öffnet Unicode-Tabelle in floating window
   - Verwendet `chrisbra/unicode.vim` Plugin
   - Customized floating window mit:
     - Rounded border
     - Title: " Unicode Table "
   - Highlight: ExCyan

## Implementierungsdetails

### Copy Marked/Selected
```lua
function()
  local lines = get_selected_text()
  if lines then
    vim.cmd("normal! gvy")  -- Copy visual selection
  else
    vim.cmd("%y+")  -- Fallback: entire buffer
  end
end
```

### Delete Marked/Selected
```lua
function()
  if has_selection() then
    vim.cmd("normal! gvd")
  else
    notify.warn("No selection to delete")
  end
end
```

### Delete File
```lua
function()
  local filepath = vim.api.nvim_buf_get_name(0)
  -- Bestätigung
  local choice = vim.fn.confirm('Delete file "' .. filename .. '"?', ...)
  if choice == 1 then
    vim.fn.delete(filepath)
    vim.cmd("bdelete!")
  end
end
```

### Unicode Table
```lua
function()
  pcall(vim.cmd, "UnicodeTable")
  -- Customize window
  vim.schedule(function()
    -- Find unicode buffer
    -- Set window config with rounded border + title
  end)
end
```

## Helper Functions

### `has_selection()`
Prüft ob Text in Visual Mode ausgewählt ist:
```lua
local mode = vim.fn.mode()
return mode == "v" or mode == "V" or mode == "\22"  -- \22 = <C-v>
```

### `get_selected_text()`
Holt ausgewählten Text in Visual Mode:
```lua
local start_pos = vim.fn.getpos("'<")
local end_pos = vim.fn.getpos("'>")
return vim.api.nvim_buf_get_lines(0, start_line - 1, end_line, false)
```

## Testing

### Copy Operations
1. **Copy All**: Öffne beliebigen Buffer → Menu → "Copy All" → `<C-v>` in anderem Buffer
2. **Copy Marked**: Markiere Text (Visual Mode) → Menu → "Copy Marked/Selected"

### Delete Operations
1. **Delete Marked**: Markiere Text → Menu → "Delete Marked/Selected"
2. **Delete All**: Menu → "Delete All" → Bestätige Dialog
3. **Delete File**: In Datei → Menu → "Delete File" → Bestätige → Datei gelöscht + Buffer geschlossen

### Unicode Table
1. Menu → "Unicode Table" → Floating window öffnet sich
2. Navigiere mit `j`/`k`
3. Schließe mit `q` oder `<Esc>`

## Integration in bestehende Keymaps

Die neuen Menu-Einträge sind auch direkt via Keymaps verfügbar:

```lua
-- In mappings/general.lua o.ä.
vim.keymap.set("n", "<C-a>", "%y+", { desc = "Copy All to clipboard" })
vim.keymap.set("v", "<C-c>", "y", { desc = "Copy selection" })
vim.keymap.set("n", "dm", function()
  if has_selection() then vim.cmd("normal! gvd") end
end, { desc = "Delete marked/selected" })
```

## Known Issues

### Unicode Table
- Benötigt `chrisbra/unicode.vim` Plugin
- Floating window customization nur wenn Plugin geladen
- Fallback: Warn-Notification wenn Plugin fehlt

### Delete File
- Keine Trash-Unterstützung (direktes `vim.fn.delete`)
- Buffer wird sofort geschlossen (`bdelete!`)
- Keine Undo-Möglichkeit
