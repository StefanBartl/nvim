1. INTRODUCTION                                  *debugging-views-introduction*

The views module provides unified management for debug views like `:messages`
and Noice output. Features include:

    • Deterministic window management via tags
    • Auto-bottom cursor positioning
    • Cross-platform clipboard integration
    • Auto-refresh on window enter
    • File persistence with timestamps
    • Graceful degradation without dependencies

==============================================================================
2. SETUP                                                *debugging-views-setup*

Minimal:~
>lua
    require("debugging.views").setup()
<

Full configuration:~
>lua
    require("debugging.views").setup({
      keymaps = {
        enable = true,
        prefix = "<leader>d",
      },
      autocmds = {
        enable = true,
        auto_refresh = true,
      },
      timings = {
        delay_messages_ms = 30,
        retry_delay_ms = 60,
        attempts = 3,
      },
    })
<

3. COMMANDS                                          *debugging-views-commands*

:DebugMessagesShow                              *:DebugMessagesShow*
    Open `:messages` output in dedicated window.

    Features:
    • Cursor automatically at bottom
    • Auto-refresh on window enter
    • Close with 'q' or <Esc>
    • Reuses existing window if open

    Example: >
        :DebugMessagesShow
<

:DebugMessagesCapture                        *:DebugMessagesCapture*
    Capture `:messages` to file and clipboard.

    Output locations:
    • File: $REPOS_DIR/debug_views/messages-TIMESTAMP.log
    • Or: stdpath("state")/debug_views/messages-TIMESTAMP.log
    • Clipboard: Cross-platform (pbcopy/wl-copy/xclip/clip.exe)

    Example: >
        :DebugMessagesCapture
<

:DebugWindowsClear                              *:DebugWindowsClear*
    Close all debug windows (messages, noice_all, noice_errors).

    Example: >
        :DebugWindowsClear
<

4. KEYMAPS                                            *debugging-views-keymaps*

Default prefix: `<leader>d`

<leader>dm                                      *<leader>dm*
    Open messages view
    Equivalent to: `:DebugMessagesShow`

<leader>dn                                      *<leader>dn*
    Open Noice all messages
    Equivalent to: `:Noice all`

<leader>de                                      *<leader>de*
    Open Noice errors only
    Equivalent to: `:Noice errors`

<leader>dc                                      *<leader>dc*
    Capture to file + clipboard
    Equivalent to: `:DebugMessagesCapture`

<leader>dx                                      *<leader>dx*
    Clear all debug windows
    Equivalent to: `:DebugWindowsClear`

Custom prefix:~
>lua
    require("debugging.views").setup({
      keymaps = { prefix = "<leader>dbg" },
    })
<

Disable keymaps:~
>lua
    require("debugging.views").setup({
      keymaps = { enable = false },
    })
<

5. API                                                  *debugging-views-api*

capture.capture_messages({opts})          *debugging-views.capture_messages()*
    Capture `:messages` with options.

    Parameters:~
        {opts}  (table|nil) Optional configuration
            • debug (boolean): Show debug notifications
            • clipboard (boolean): Copy to clipboard (default: true)
            • save_file (boolean): Save to file (default: true)
            • output_dir (string): Custom output directory

    Returns:~
        boolean success, string|nil content

    Example: >lua
        local capture = require("debugging.views.capture")
        local ok, content = capture.capture_messages({
          debug = true,
          clipboard = true,
        })
<

display.execute_and_refresh({tag}, {cmd}, {timings})
                                     *debugging-views.execute_and_refresh()*
    Execute command and manage window state.

    Parameters:~
        {tag}      (string) Window tag ("messages", "noice_all", "noice_errors")
        {cmd}      (string) Command to execute (":messages", ":Noice all")
        {timings}  (table) Timing configuration

    Example: >lua
        local display = require("debugging.views.display")
        display.execute_and_refresh("messages", "messages", {
          attempts = 3,
          retry_delay_ms = 60,
        })
<

utils.focus_and_bottom({win}, {attempts}, {retry_delay})
                                        *debugging-views.focus_and_bottom()*
    Focus window and move cursor to bottom.

    Parameters:~
        {win}          (integer) Window ID
        {attempts}     (integer) Max retry attempts
        {retry_delay}  (integer) Delay between retries (ms)

    Example: >lua
        local utils = require("debugging.views.utils")
        utils.focus_and_bottom(1000, 3, 60)
<

utils.make_focusable({win})                 *debugging-views.make_focusable()*
    Ensure window is focusable.

    Parameters:~
        {win}  (integer) Window ID

    Returns:~
        boolean success

    Example: >lua
        local utils = require("debugging.views.utils")
        if utils.make_focusable(win) then
          vim.api.nvim_set_current_win(win)
        end
<

display.clear_all()                              *debugging-views.clear_all()*
    Close all debug windows.

    Example: >lua
        require("debugging.views.display").clear_all()
<

6. CONFIGURATION                                    *debugging-views-config*

Full schema:~
>lua
    {
      keymaps = {
        enable = true,              -- Enable default keymaps
        map = vim.keymap.set,       -- Custom keymap function
        prefix = "<leader>d",       -- Keymap prefix
      },
      autocmds = {
        enable = true,              -- Enable autocommands
        group_name = "DebugViewsAuto",
        auto_refresh = true,        -- Auto-refresh on WinEnter
      },
      timings = {
        delay_messages_ms = 30,     -- Initial delay for :messages
        delay_noice_ms = 50,        -- Initial delay for Noice
        retry_delay_ms = 60,        -- Retry delay for cursor
        attempts = 3,               -- Max retry attempts
      },
    }
<

Timings explanation:~
    • delay_messages_ms: Wait before showing :messages window
    • delay_noice_ms: Wait before showing Noice window
    • retry_delay_ms: Delay between cursor-at-bottom retries
    • attempts: How many times to retry cursor positioning

7. TROUBLESHOOTING                          *debugging-views-troubleshooting*

Clipboard not working~

Symptom: "clipboard not available" warning

Solution: Install clipboard provider:
    • macOS: pbcopy (built-in)
    • Wayland: sudo apt install wl-clipboard
    • X11: sudo apt install xclip (or xsel)
    • WSL: clip.exe (built-in)

Check available providers: >vim
    :checkhealth debugging
<

Window not focusing~

Symptom: Window opens but cursor not visible

Check window config: >lua
    local win = vim.api.nvim_get_current_win()
    local config = vim.api.nvim_win_get_config(win)
    print(vim.inspect(config))
    -- Should have: focusable = true
<

Force focusable: >lua
    local utils = require("debugging.views.utils")
    utils.make_focusable(win)
    utils.force_focus(win)
<

Auto-refresh not working~

Symptom: Messages window shows stale content

Enable auto-refresh: >lua
    require("debugging.views").setup({
      autocmds = { auto_refresh = true },
    })
<

Check autocommands: >vim
    :au DebugViewsAuto
<

Cursor not at bottom~

Symptom: Cursor stays at top of messages

Increase retry attempts: >lua
    require("debugging.views").setup({
      timings = {
        retry_delay_ms = 100,
        attempts = 5,
      },
    })
<
