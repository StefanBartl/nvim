1. INTRODUCTION                                        *debugging-introduction*

The `debugging` module provides a unified suite of tools for inspecting,
logging, and debugging Neovim's internal state. All modules are type-safe,
cross-platform compatible, and modular.

Key Features:~
    • Unified debug views (:messages, Noice)
    • Variable dumping utilities
    • Buffer/Tab/Window inspection
    • Terminal keylogging
    • Markdown highlight debugging
    • Cursor state inspection
    • Autocommand inspection

==============================================================================
2. SETUP                                                      *debugging-setup*

Minimal setup:~
>lua
    require("debugging").setup()
<

Custom setup example:~
>lua
require("debugging").setup({
  views = {
    keymaps = { enable = true, prefix = "<leader>d" },
    autocmds = { enable = true, auto_refresh = true },
  },
  usercmds = true,
  tools = { vardump = true, cursor_state = true },
})
<

3. MODULES                                                  *debugging-modules*

The debugging system is organized into modular components:

views~                                                     |debugging-views.txt|
    Unified debug views for `:messages` and Noice with window management,
    auto-refresh, and clipboard integration.

usercmds~                                             |debugging-usercmds.txt|
    Report commands for buffer, tab, and window inspection.

tools~                                                 |debugging-tools.txt|
    Utilities for inspecting variables, cursor state, and buffers.

    Submodules:~
        vardump~                                       |debugging-tools-vardump|
            Dump Lua variables and tables recursively (via `:VardumpVar`).

        cursor_state~                                  |debugging-tools-cursor|
            Inspect and track cursor positions per buffer.

        buffer_inspector~                              |debugging-tools-buffer|
            Inspect buffer properties like filetype, options, and lines.

terminals~                                           |debugging-terminals.txt|
    Terminal debugging tools including keylogger.

nvim_options~                                   |debugging-nvim-options.txt|
    Helpers for inspecting and toggling Neovim options.

markdown~                                             |debugging-markdown.txt|
    Tools for debugging Markdown syntax highlighting issues.

cursor~                                                 |debugging-cursor.txt|
    Cursor state inspection utilities.

autocmds~                                             |debugging-autocmds.txt|
    Autocommand listing and inspection.

6. CONFIGURATION                                           *debugging-config*

Full configuration schema:~
>lua
require("debugging").setup({
  views = {
    keymaps = { enable = true, prefix = "<leader>d" },
    autocmds = { enable = true, auto_refresh = true },
    timings = { delay_messages_ms = 30, delay_noice_ms = 50, retry_delay_ms = 60, attempts = 3 },
    capture = { debug = false, clipboard = true, save_file = true },
  },
  usercmds = true,
  tools = { vardump = true, cursor_state = true },
  markdown = { inline_debug_fixed = false },
  terminals = { keylogger = false },
  autocmds = { list_autocmds = false },
})
<

7. HEALTH CHECK                                           *debugging-health*

Run health check:~
>vim
    :checkhealth debugging
<

Checks:
    • Clipboard support
    • File write permissions for debug_views
    • Required helper libraries
    • Module availability

==============================================================================
8. TROUBLESHOOTING                                       *debugging-troubleshooting*

Clipboard issues:
    Install OS-specific clipboard provider.

Stale debug views:
    Enable auto_refresh in configuration.

Missing commands:
    Verify required libraries or modules are installed.

Window focus issues:
    Ensure `focusable = true` in window config.
