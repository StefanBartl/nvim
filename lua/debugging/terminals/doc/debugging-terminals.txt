1. INTRODUCTION                           *debugging-terminals-introduction*

The terminals module provides debugging tools for terminal buffers,
including a keylogger for inspecting terminal input. Useful for debugging
terminal keymaps, special character handling, and key sequence issues.

==============================================================================
2. COMMANDS                                   *debugging-terminals-commands*

:TerminalKeyLoggerStart                            *:TerminalKeyLoggerStart*
    Start logging all keypresses in current terminal buffer.

    Requirements:~
        • Current buffer must be terminal (buftype == "terminal")

    Behavior:~
        • Captures keys via vim.fn.getcharstr()
        • Displays each key via vim.notify()
        • Runs in background via vim.schedule()
        • Continues until :TerminalKeyLoggerStop called

    Example: >
        :terminal
        :TerminalKeyLoggerStart

        " Press keys
        i
        j
        k
        <C-c>

        " Output in :messages:
        [terminal_keylogger] Key pressed: "i"
        [terminal_keylogger] Key pressed: "j"
        [terminal_keylogger] Key pressed: "k"
        [terminal_keylogger] Key pressed: "\3"
<

:TerminalKeyLoggerStop                              *:TerminalKeyLoggerStop*
    Stop terminal keylogging.

    Example: >
        :TerminalKeyLoggerStop
        " [terminal_keylogger] Stopped logging keys.
<

3. USE CASES                                   *debugging-terminals-use-cases*

Debug terminal keymaps:~

    Find which keys are sent to terminal:
>vim
    :terminal
    :TerminalKeyLoggerStart

    " Press your keymap
    <C-h>

    " Check :messages
    " [terminal_keylogger] Key pressed: "\8"  (ASCII backspace)
<

Inspect special characters:~

    See how special keys are represented:
>vim
    :TerminalKeyLoggerStart

    <C-c>    → "\3"
    <C-d>    → "\4"
    <Esc>    → "\27"
    <Tab>    → "\t"
    <Enter>  → "\r" or "\n"
<

Debug key sequences:~

    Capture multi-key sequences:
>vim
    :TerminalKeyLoggerStart

    " Type: jj
    [terminal_keylogger] Key pressed: "j"
    [terminal_keylogger] Key pressed: "j"
<

Test terminal integration:~

    Verify terminal receives expected input:
>vim
    :TerminalKeyLoggerStart

    " Type command
    ls -la

    " Verify each character logged correctly
<

4. API                                             *debugging-terminals-api*

Module state:~
>lua
    local M = require("debugging.terminals.keylogger")

    -- Check if logging active
    print(M.logging)  -- boolean

    -- Get current buffer
    print(M.bufnr)    -- integer|nil
<

M.start()                                    *debugging-terminals.start()*
    Start keylogging in current terminal buffer.

    Returns:~
        nil

    Side effects:~
        • Sets M.logging = true
        • Sets M.bufnr = current buffer
        • Starts recursive capture loop

    Example: >lua
        local keylogger = require("debugging.terminals.keylogger")
        keylogger.start()
<

M.stop()                                      *debugging-terminals.stop()*
    Stop keylogging.

    Returns:~
        nil

    Side effects:~
        • Sets M.logging = false
        • Stops capture loop

    Example: >lua
        local keylogger = require("debugging.terminals.keylogger")
        keylogger.stop()
<

5. ARCHITECTURE                           *debugging-terminals-architecture*

How it works:~

    1. Activation
       :TerminalKeyLoggerStart sets M.logging = true

    2. Capture Loop
       log_key() function runs recursively via vim.schedule()

    3. Key Reading
       vim.fn.getcharstr() blocks until next keypress

    4. Notification
       Each key logged via vim.notify()

    5. Termination
       :TerminalKeyLoggerStop sets M.logging = false

Code flow:~
>lua
    function log_key()
      if not M.logging then return end

      vim.schedule(function()
        if not M.logging then return end

        local ok, key = pcall(vim.fn.getcharstr)
        if ok and key then
          vim.notify(string.format(
            "[terminal_keylogger] Key pressed: %q", key))
        end

        if M.logging then
          log_key()  -- Recursive call
        end
      end)
    end
<

6. LIMITATIONS                             *debugging-terminals-limitations*

Terminal buffers only:~

    Keylogger only works in terminal buffers.

    Check buffer type: >lua
        print(vim.bo.buftype)  -- Should be "terminal"
<

    Workaround: None (by design for safety)

Blocking behavior:~

    vim.fn.getcharstr() blocks the event loop.

    Impact: Neovim may appear frozen waiting for input

    Mitigation: vim.schedule() yields between captures

No replay functionality:~

    Logged keys are display-only, not recorded to file.

    Future enhancement: Add optional file output
    See: |debugging-roadmap|

Performance:~

    Minimal impact due to async scheduling.

    Each key adds small notification overhead.

==============================================================================
7. SAFETY                                       *debugging-terminals-safety*

Password capture warning:~

    WARNING: Keylogger captures ALL input including passwords!

    Best practice:
        • Stop logging before entering sensitive data
        • Clear :messages after debugging:
>vim
            :messages clear
<

Buffer scope:~

    Keylogger only affects buffer where started.

    Other terminals unaffected.

No file output:~

    Keys not saved to disk (display only).

    Prevents accidental password storage.

Manual control:~

    No automatic activation.

    User must explicitly start/stop logging.

8. TROUBLESHOOTING                     *debugging-terminals-troubleshooting*

Keylogger not starting~

Symptom: "Already logging!" warning

Cause: Keylogger already active

Solution: >vim
    :TerminalKeyLoggerStop
    :TerminalKeyLoggerStart

    " Or force reset:
    :lua require("debugging.terminals.keylogger").logging = false
<

Not a terminal buffer~

Symptom: No keys logged

Cause: Current buffer not terminal

Solution: >vim
    " Check buffer type
    :lua print(vim.bo.buftype)  -- Should be "terminal"

    " Open terminal first
    :terminal
    :TerminalKeyLoggerStart
<

Keys not showing~

Symptom: Keylogger started but no output

Cause: Keys consumed by terminal before logger

This is expected for some terminal-specific keys.
Logger captures input, not terminal processing.

Neovim frozen~

Symptom: Neovim unresponsive

Cause: getcharstr() blocking

Solution: >
    Press any key to continue

    Or restart Neovim if truly frozen
<

Too many notifications~

Symptom: :messages flooded

Solution: >vim
    " Clear messages
    :messages clear

    " Stop logging
    :TerminalKeyLoggerStop
<
