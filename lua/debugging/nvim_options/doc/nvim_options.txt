1. INTRODUCTION                       *debugging-nvim-options-introduction*

The nvim_options module provides helpers for inspecting and toggling Neovim
options, with focus on indentation and syntax providers. Useful for debugging
indentation issues and comparing indent providers.

==============================================================================
2. API                                         *debugging-nvim-options-api*

print_indent_options([{bufnr}])      *debugging-nvim-options.print_indent_options()*
    Print current indentation-related buffer options.

    Parameters:~
        {bufnr}  Optional. Buffer number (default: current buffer)

    Prints:~
        • autoindent      Copy indent from current line
        • smartindent     Smart auto-indent for C-like code
        • cindent         C-style indenting
        • indentexpr      Expression for indent calculation
        • indentkeys      Keys that trigger indent recalculation
        • shiftwidth      Spaces per indent step
        • tabstop         Spaces per <Tab>

    Example: >vim
        :lua require("debugging.nvim_options.indent_helpers").print_indent_options()

        " Output:
        {
          autoindent = true,
          cindent = false,
          indentexpr = "v:lua.require'nvim-treesitter.indent'.get_indent()",
          indentkeys = "0{,0},0),0],:,0#,!^F,o,O,e",
          shiftwidth = 2,
          smartindent = false,
          tabstop = 2
        }
<

    For specific buffer: >lua
        local helpers = require("debugging.nvim-options.indent_helpers")
        helpers.print_indent_options(5)  -- Buffer 5
<

prefer_treesitter_indent([{enable}]) *debugging-nvim-options.prefer_treesitter_indent()*
    Toggle tree-sitter indent by disabling cindent/smartindent.

    Parameters:~
        {enable}  Optional. Enable preference (default: true)

    Behavior:~
        When enable = true:
            • Disables cindent
            • Disables smartindent
            • Lets tree-sitter indentexpr take effect

        When enable = false:
            • Restores defaults (both off)

    Why this works:~
        Neovim indent priority:
        1. indentexpr (highest - tree-sitter uses this)
        2. cindent
        3. smartindent
        4. autoindent (lowest)

        Disabling cindent/smartindent lets tree-sitter win.

    Example: >vim
        " Enable tree-sitter indent
        :lua require("debugging.nvim-options.indent_helpers").prefer_treesitter_indent(true)
        " treesitter-prefer mode for lua set to true

        " Verify
        :lua require("debugging.nvim-options.indent_helpers").print_indent_options()
        " {
        "   cindent = false,
        "   smartindent = false,
        "   indentexpr = "v:lua.require'nvim-treesitter.indent'.get_indent()",
        "   ...
        " }
<

3. INDENT PROVIDERS                   *debugging-nvim-options-providers*

Tree-sitter (Recommended):~                 *debugging-nvim-options-treesitter*

    Pros:
        • Syntax-aware
        • Language-specific
        • Most accurate

    Setup: >lua
        require("nvim-treesitter.configs").setup({
          indent = { enable = true },
        })

        require("debugging.nvim-options.indent_helpers")
          .prefer_treesitter_indent()
<

    Check: >vim
        :lua print(vim.bo.indentexpr)
        " v:lua.require'nvim-treesitter.indent'.get_indent()
<

cindent:~                                      *debugging-nvim-options-cindent*

    Pros:
        • Fast
        • Built-in
        • Good for C-like languages

    Cons:
        • Not syntax-aware
        • Limited language support

    Enable: >vim
        :set cindent
<

smartindent:~                              *debugging-nvim-options-smartindent*

    Pros:
        • Simple
        • Fast
        • Works for many languages

    Cons:
        • Basic heuristics
        • No syntax awareness

    Enable: >vim
        :set smartindent
<

autoindent:~                                *debugging-nvim-options-autoindent*

    Pros:
        • Universal
        • Always available
        • No language knowledge needed

    Cons:
        • Just copies previous line indent
        • No smart adjustments

    Enable: >vim
        :set autoindent
<

4. USE CASES                               *debugging-nvim-options-use-cases*

Debug indentation issues:~

    When indentation doesn't work as expected:
>vim
    :lua require("debugging.nvim-options.indent_helpers").print_indent_options()

    " Check which provider active:
    " - indentexpr set? → Tree-sitter or custom
    " - cindent true? → C-style
    " - smartindent true? → Smart auto-indent
<

Switch to tree-sitter:~

    Force tree-sitter indentation:
>vim
    :lua require("debugging.nvim-options.indent_helpers").prefer_treesitter_indent()
<

Compare providers:~

    Test different indent providers:
>lua
    local helpers = require("debugging.nvim-options.indent_helpers")

    -- Test tree-sitter
    helpers.prefer_treesitter_indent(true)
    -- Try indenting code

    -- Test cindent
    vim.bo.cindent = true
    -- Try indenting code

    -- Test smartindent
    vim.bo.smartindent = true
    -- Try indenting code
<

Per-filetype config:~

    In ftplugin/lua.lua:
>lua
    local helpers = require("debugging.nvim-options.indent_helpers")
    helpers.prefer_treesitter_indent(true)
<

5. CONFIGURATION                           *debugging-nvim-options-config*

Global setup:~

    Prefer tree-sitter for all buffers:
>lua
    vim.api.nvim_create_autocmd("FileType", {
      callback = function()
        if vim.treesitter.language.get_lang(vim.bo.filetype) then
          require("debugging.nvim-options.indent_helpers")
            .prefer_treesitter_indent()
        end
      end,
    })
<

Per-language:~

    In ftplugin/python.lua:
>lua
    require("debugging.nvim-options.indent_helpers")
      .prefer_treesitter_indent()
    vim.bo.shiftwidth = 4
    vim.bo.tabstop = 4
<

With keymaps:~
>lua
    vim.keymap.set("n", "<leader>di", function()
      require("debugging.nvim-options.indent_helpers")
        .print_indent_options()
    end, { desc = "Debug indent options" })

    vim.keymap.set("n", "<leader>dt", function()
      require("debugging.nvim-options.indent_helpers")
        .prefer_treesitter_indent()
    end, { desc = "Prefer tree-sitter indent" })
<

6. TROUBLESHOOTING                 *debugging-nvim-options-troubleshooting*

Tree-sitter indent not working~

Symptom: Code not indenting correctly despite tree-sitter enabled

Diagnosis: >lua
    local helpers = require("debugging.nvim-options.indent_helpers")
    helpers.print_indent_options()

    -- Check:
    -- 1. indentexpr should contain "treesitter"
    -- 2. cindent and smartindent should be false
<

Solution: >lua
    helpers.prefer_treesitter_indent(true)
<

Conflicting indent providers~

Symptom: Indentation inconsistent or wrong

Cause: Multiple providers active (cindent + smartindent)

Solution: >lua
    vim.bo.cindent = false
    vim.bo.smartindent = false
    -- Tree-sitter indentexpr remains
<

indentexpr not set~

Symptom: indentexpr is empty

Cause: Tree-sitter indent module not enabled

Solution: >lua
    require("nvim-treesitter.configs").setup({
      indent = { enable = true },
    })
<

Wrong indentation level~

Symptom: Indents too much or too little

Check settings: >vim
    :set shiftwidth?
    :set tabstop?
    :set expandtab?
<

Solution: >vim
    :set shiftwidth=2
    :set tabstop=2
    :set expandtab
<
