1. INTRODUCTION                                *debugging-cursor-introduction*

The cursor module provides utilities for inspecting cursor position, window
state, buffer validity, and Neovim mode. Useful for debugging focus issues,
window management problems, and cursor positioning bugs.

==============================================================================
2. USAGE                                              *debugging-cursor-usage*

Basic usage:~
>lua
    local cursor = require("debugging.cursor.state")
    cursor.debug_state()
<

Output to :messages:~
    === Cursor Debug State ===
    Current Win ID: 1000
    Win Valid: true
    Buffer ID: 5
    Buf Valid: true
    Buf Lines: 100
    Cursor Pos: {10, 5}
    Mode: n
    Window Tag: none

    === All Windows ===
    Win 1000: tag=none
    Win 1001: tag=messages

In command mode:~
>vim
    :lua require("debugging.cursor.state").debug_state()
<

3. API                                                  *debugging-cursor-api*

debug_state()                                    *debugging-cursor.debug_state()*
    Print comprehensive cursor and window state.

    Output includes:
    • Current window ID
    • Window validity
    • Buffer ID and validity
    • Buffer line count
    • Cursor position {row, col}
    • Current mode
    • Window tag (if set)
    • List of all windows

    Example: >lua
        require("debugging.cursor.state").debug_state()
<

==============================================================================
4. OUTPUT REFERENCE                                *debugging-cursor-output*

Current Win ID: {number}                          *debugging-cursor-win-id*
    Numeric ID of current window from nvim_get_current_win().

Win Valid: {boolean}                              *debugging-cursor-win-valid*
    Result of nvim_win_is_valid(win).
    false indicates window no longer exists.

Buffer ID: {number}|ERROR                         *debugging-cursor-buf-id*
    Buffer displayed in current window.
    "ERROR" if nvim_win_get_buf() fails.

Buf Valid: {boolean}                              *debugging-cursor-buf-valid*
    Result of nvim_buf_is_valid(buf).
    false indicates buffer was deleted.

Buf Lines: {number}                               *debugging-cursor-buf-lines*
    Total line count from nvim_buf_line_count(buf).

Cursor Pos: {{row}, {col}}                        *debugging-cursor-pos*
    Cursor position from nvim_win_get_cursor().
    1-indexed: {row, col} where row=1 is first line.

Mode: {string}                                    *debugging-cursor-mode*
    Current Neovim mode from nvim_get_mode().mode

    Common modes:
        n     Normal
        i     Insert
        v     Visual (character-wise)
        V     Visual Line
        ^V    Visual Block
        c     Command-line
        t     Terminal
        R     Replace
        s,S   Select

Window Tag: {string}|none                         *debugging-cursor-tag*
    Custom tag from vim.w[win].custom_tag

    Used by debugging.views for window tracking:
        "messages"      :messages window
        "noice_all"     Noice all window
        "noice_errors"  Noice errors window

All Windows:                                      *debugging-cursor-all-wins*
    Lists all windows with format:
        Win {id}: tag={tag}

    Example:
        Win 1000: tag=none
        Win 1001: tag=messages

5. INTEGRATION                                  *debugging-cursor-integration*

With views module:~
    Cursor debugging integrates with window tagging from |debugging-views|
>lua
    -- Open messages view
    vim.cmd("DebugMessagesShow")

    -- Check cursor state
    require("debugging.cursor.state").debug_state()
    -- Output shows: Window Tag: messages
<

In autocommands:~
    Debug cursor state on events:
>lua
    vim.api.nvim_create_autocmd("WinEnter", {
      callback = function()
        require("debugging.cursor.state").debug_state()
      end,
    })
<

In keymaps:~
    Quick cursor inspection:
>lua
    vim.keymap.set("n", "<leader>dc", function()
      require("debugging.cursor.state").debug_state()
    end, { desc = "Debug cursor state" })
<

With :WinReport:~
    Combine with |:WinReport| for detailed window info:
>vim
    :lua require("debugging.cursor.state").debug_state()
    :WinReport
<

6. TROUBLESHOOTING                          *debugging-cursor-troubleshooting*

ERROR in output~

Symptom: Buffer ID: ERROR

Cause: pcall failed, window likely invalid

Solution: Check if window exists: >lua
    print(vim.inspect(vim.api.nvim_list_wins()))
<

Cursor position unexpected~

Symptom: Shows {1, 0} but cursor visually elsewhere

Cause: Multiple windows displaying same buffer

Solution: Use :WinReport to check all windows: >vim
    :WinReport
<

Window tag always "none"~

Symptom: All windows show tag=none

Cause: Tags only set by specific modules

This is normal - regular editor windows don't have tags.
Only debugging.views sets tags for tracking.

Mode shows unexpected value~

Symptom: Mode is "n" but in insert mode

Cause: State captured between mode transitions

Solution: Check again or inspect blocking mode: >lua
    print(vim.inspect(vim.api.nvim_get_mode()))
    -- { blocking = false, mode = "n" }
<
