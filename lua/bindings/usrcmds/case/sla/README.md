# bindings.usrcmds.case.sla

casedesk's SLA layer (`docs/ROADMAP/casedesk/SLA.md`): given a case,
determines which of the three SAP-SLA clocks (Erstreaktion, laufende
Rückmeldung, Korrekturmaßnahme) apply and how much time is left on each.
Surfaces two "ticket opened" anchors side by side rather than picking one.
