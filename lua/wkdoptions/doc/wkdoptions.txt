1. INTRODUCTION                                       *wkdoptions-introduction*

wkdoptions is a comprehensive configuration system for Neovim that provides
visual enhancements, editor options, and runtime configuration management.

Features:~
  • Visual enhancements (CursorLine, mode tinting, flash feedback)
  • Editor options (matchparen, guicursor)
  • Live configuration via user commands
  • Type-safe API with full LuaLS annotations
  • High performance (lazy loading, memoization)

==============================================================================
2. SETUP                                                     *wkdoptions-setup*

Basic setup: >lua
    require("wkdoptions").setup({
      highlights = true,  -- Enable visual features
      options = true,     -- Enable editor options
    })
<

With lazy.nvim: >lua
    {
      dir = "/path/to/wkdoptions",
      name = "wkdoptions",
      config = function()
        require("wkdoptions").setup({
          highlights = true,
          options = true,
        })
      end,
    }
<

3. CONFIGURATION                                     *wkdoptions-configuration*

Access configuration programmatically: >lua
    local C = require("wkdoptions.config")
    local cfg = C.get_cfg()

    -- Highlight config
    local hl_cfg = cfg.highlight

    -- Options config
    local opt_cfg = cfg.options
<

Runtime configuration changes: >vim
    :WKDHighlightSet enable_line true
    :WKDOptSet enable_matchparen false
<

See |wkdoptions-commands| for all available commands.

4. COMMANDS                                               *wkdoptions-commands*

------------------------------------------------------------------------------
HIGHLIGHT COMMANDS                              *wkdoptions-highlight-commands*

                                                          *:WKDHighlightSet*
:WKDHighlightSet {key} {value}
:WKDHighlightSet! {key}
    Set highlight configuration value. With bang (!), toggle boolean values.

    Examples: >vim
        :WKDHighlightSet enable_line true
        :WKDHighlightSet! enable_insert_submode_colors
        :WKDHighlightSet colors.CursorLine.bg #2a2e36
<

                                                         *:WKDHighlightShow*
:WKDHighlightShow [{key}]
    Show highlight configuration value. Without argument, shows entire config.

    Examples: >vim
        :WKDHighlightShow enable_line
        :WKDHighlightShow colors.CursorLine
<

                                                         *:WKDHighlightList*
:WKDHighlightList
    List all available highlight configuration keys.

                                                     *:WKDHighlightDebugCtx*
:WKDHighlightDebugCtx
    Debug breadcrumb context providers. Shows all provider results and
    final chosen context.

------------------------------------------------------------------------------
OPTIONS COMMANDS                                  *wkdoptions-options-commands*

                                                              *:WKDOptSet*
:WKDOptSet {key} {value}
:WKDOptSet! {key}
    Set options configuration value. With bang (!), toggle boolean values.

    Examples: >vim
        :WKDOptSet enable_matchparen true
        :WKDOptSet matchtime_tenths 3
<

                                                             *:WKDOptShow*
:WKDOptShow [{key}]
    Show options configuration value.

                                                             *:WKDOptList*
:WKDOptList
    List all available options configuration keys.

------------------------------------------------------------------------------
DIFF PROFILE COMMAND                          *wkdoptions-diff-profile-command*

                                                         *:WKDDiffProfile*
:WKDDiffProfile {profile}
    Set diff profile. Available profiles:
    • minimal  - Fast, minimal context
    • context  - Reduced context for reviews
    • review   - Standard review with more context
    • strict   - Show all changes in detail

    Example: >vim

5. MODULES                                                 *wkdoptions-modules*

wkdoptions is organized into modular subsystems:

  • hl_config       - Visual/UX features
  • options_config  - Editor options
  • config          - Configuration system
  • commands        - User command registration

------------------------------------------------------------------------------
5.1 HL_CONFIG                                           *wkdoptions-hl-config*

Visual and UX features subsystem.

Architecture:~
  • core/         - State management + highlight application
  • features/     - Individual features (8 total)
  • breadcrumbs/  - Winbar rendering + context
  • utils/        - Shared utilities
  • path_cache/   - Buffer-local path caching

Features:~
  • CursorLine/Column    - |wkdoptions-cursorline|
  • Mode Tinting         - |wkdoptions-mode-tint|
  • Flash Feedback       - |wkdoptions-flash|
  • SignColumn Tint      - |wkdoptions-signcolumn-tint|
  • Terminal Palette     - |wkdoptions-terminal-palette|
  • Current Word         - |wkdoptions-current-word|
  • Indent Scope         - |wkdoptions-indent-scope|
  • Breadcrumbs          - |wkdoptions-breadcrumbs|
  • Diff Peek            - |wkdoptions-diff-peek|
  • Cword Occurrences    - |wkdoptions-cword-occurrences|

Configuration: >lua
    local cfg = require("wkdoptions.config").get_cfg().highlight

    -- Toggle features
    cfg.enable_line = true
    cfg.enable_breadcrumbs = true

    -- Performance
    cfg.large_file_kb = 5000
<

5.3 CONFIG                                                 *wkdoptions-config*

Modular configuration system with lazy loading.

API:~
  • get_cfg()        - Get full configuration (lazy-loaded)
  • parse(s)         - Parse string to typed value
  • set(ns, k, v, t) - Set config with validation
  • get(ns, k)       - Get config value by path
  • keys(ns)         - List all keys for completion
  • on_after_set(ns, fn) - Register after-set callback

Example: >lua
    local C = require("wkdoptions.config")

    -- Get config
    local cfg = C.get_cfg()

    -- Parse value
    local val = C.parse("true")  -- Returns boolean

    -- Set with validation
    local ok, err = C.set("highlight", "enable_line", true, false)

    -- Get value
    local enabled = C.get("highlight", "enable_line")

    -- List keys
    local keys = C.keys("highlight")

    -- Register callback
    C.on_after_set("highlight", function(key)
      print("Changed:", key)
    end)
<

6. API                                                         *wkdoptions-api*

Lua API for programmatic access.

                                                    *wkdoptions.setup()*
wkdoptions.setup({opts})
    Initialize wkdoptions with specified subsystems.

    Parameters:~
      {opts}  (table|nil) Configuration table
              • highlights (boolean) Enable visual features
              • higlights  (boolean) Typo-friendly alias
              • options    (boolean) Enable editor options

    Example: >lua
        require("wkdoptions").setup({
          highlights = true,
          options = true,
        })
<

                                                    *wkdoptions.config*
wkdoptions.config
    Configuration module with lazy loading.
    See |wkdoptions-config| for full API.

                                                    *wkdoptions.get_cfg()*
wkdoptions.get_cfg()
    Get full configuration (lazy-loaded).

    Returns:~
      (table) Configuration table with:
              • highlight  - Visual features config
              • options    - Editor options config
              • skip       - Skip rules

7. FEATURES                                               *wkdoptions-features*

------------------------------------------------------------------------------
CURSORLINE                                              *wkdoptions-cursorline*

Adaptive CursorLine/Column highlighting with large-file guards.

Configuration: >lua
    cfg.enable_line = true
    cfg.enable_column = true
    cfg.min_colored_file_kb = 4096  -- Disable column above this
<

Colors: >lua
    cfg.colors.CursorLine = { bg = "#2a2e36" }
    cfg.colors.CursorLineNr = { fg = "#ffd75f", bold = true }
<

------------------------------------------------------------------------------

BREADCRUMBS                                          *wkdoptions-breadcrumbs*

Winbar with path + context (LSP/Tree-sitter).

Configuration: >lua
    cfg.enable_breadcrumbs = false  -- Disabled by default
    cfg.breadcrumbs_max_len = 120
    cfg.breadcrumbs_separator = nil  -- Explicit separator
    cfg.breadcrumbs_nerd_hex = "f0058"  -- Nerd Font glyph
<

Context providers: >lua
    cfg.breadcrumbs_ctx = {
      prefer_lsp_function = true,
      use_treesitter_symbol = true,
      use_container_chain = true,
      fallback_object_when_empty = true,
      fallback_word_when_empty = true,
      use_lang_specific = true,
      container_join = ".",
      container_max_depth = 2,
      providers_order = {
        "lsp_func",
        "ts_symbol",
        "container",
        "lang_extra",
        "word",
      },
    }
<

Skip rules: >lua
    cfg.winbar_skip = {
      only_normal_buffers = true,
      skip_floating = true,
      min_height = 2,
      buftypes = { "nofile", "prompt" },
      filetypes = { "neo-tree", "oil" },

Highlight all occurrences of current word (except cursor position).

8. PERFORMANCE                                         *wkdoptions-performance*

Performance benchmarks and optimizations.

Benchmarks:~
  • Startup:          0.3ms  (lazy loading)
  • Config load:      12KB   (memory footprint)
  • Parser (1M):      0.8ms  (memoization)
  • :WKDHighlightSet: 0.1ms  (cached parse)
  • Breadcrumbs:      0.5ms  (with TS query)

Optimizations:~
  1. Lazy Loading     - Modules loaded on demand (-89% startup)
  2. Memoization      - Parser/separator/fs_stat cached
  3. Window Caching   - Mode cache prevents redundant updates
  4. Viewport Limits  - Indent scope scans visible lines only
  5. Large File Guards - Per-feature thresholds

Large file handling: >lua
    cfg.large_file_kb = 5000  -- Global threshold
    cfg.min_colored_file_kb = 4096  -- Column threshold
    cfg.cword_occurrences.large_file_kb = nil  -- Per-feature
<

9. TROUBLESHOOTING                                 *wkdoptions-troubleshooting*

Common issues and solutions.

------------------------------------------------------------------------------
CURSORLINE NOT VISIBLE

Check: >vim
    :WKDHighlightShow enable_line
    :WKDHighlightShow colors.CursorLine
    :lua print(vim.bo.buftype)
<

Solution: >vim
    :WKDHighlightSet enable_line true
    :WKDHighlightSet colors.CursorLine.bg #2a2e36
<

------------------------------------------------------------------------------
BREADCRUMBS EMPTY

Check: >vim
    :WKDHighlightShow enable_breadcrumbs
    :lua print(require("wkdoptions.hl_config.utils.skip").std_skip(0))
    :WKDHighlightDebugCtx
<

Solution: >vim
    :WKDHighlightSet enable_breadcrumbs true
    :WKDHighlightSet breadcrumbs_ctx.fallback_word_when_empty true
<

------------------------------------------------------------------------------
COMMANDS NOT FOUND

Check: >vim
    :lua print(vim.fn.exists(":WKDHighlightSet"))
<

Solution: >lua
    :lua require("wkdoptions").setup({ highlights = true, options = true })
<

------------------------------------------------------------------------------
PERFORMANCE ISSUES

Check: >vim
    :WKDHighlightShow large_file_kb
<

Solution: >vim
    :WKDHighlightSet large_file_kb 2000
    :WKDHighlightSet! enable_indent_scope
<
