## Trouble

| **Befehl**                     | **Beschreibung**                                                                                     |
|--------------------------------|-----------------------------------------------------------------------------------------------------|
| `:Trouble`                     | Öffnet das Trouble-Fenster im Standardmodus.                                                       |
| `:Trouble diagnostics`         | Zeigt alle Diagnosen (LSP, Linter, etc.) des aktuellen Workspaces oder Dokuments an.               |
| `:Trouble fzf`                 | Integriert mit FZF (falls installiert), um Diagnosen zu durchsuchen.                              |
| `:Trouble fzf_files`           | Durchsucht Dateien mit FZF-Integration (falls vorhanden).                                         |
| `:Trouble loclist`             | Zeigt die Location List von Neovim an, z. B. Ergebnisse von `:lgrep`.                             |
| `:Trouble lsp`                 | Allgemeine LSP-Integration.                                                                      |
| `:Trouble lsp_command`         | Startet LSP-spezifische Befehle.                                                                  |
| `:Trouble lsp_declarations`    | Zeigt die Deklarationen einer Funktion oder Variable.                                             |
| `:Trouble lsp_definitions`     | Zeigt Definitionen von Funktionen, Variablen oder Klassen.                                        |
| `:Trouble lsp_document_symbols`| Listet alle Symbole im aktuellen Dokument auf.                                                    |
| `:Trouble lsp_implementations` | Zeigt Implementierungen von Methoden, Klassen oder Interfaces.                                    |
| `:Trouble lsp_incoming_calls`  | Zeigt alle eingehenden Funktionsaufrufe.                                                          |
| `:Trouble lsp_outgoing_calls`  | Zeigt alle ausgehenden Funktionsaufrufe.                                                          |
| `:Trouble lsp_references`      | Zeigt alle Referenzen für die aktuelle Variable oder Funktion.                                    |
| `:Trouble lsp_type_definitions`| Zeigt die Typdefinition einer Variable oder Klasse.                                               |
| `:Trouble qflist`              | Zeigt die Quickfix-Liste von Neovim an.                                                          |
| `:Trouble quickfix`            | Alias für `:Trouble qflist`.                                                                      |
| `:Trouble symbols`             | Zeigt Symbole wie Funktionen, Variablen und Klassen für die aktuelle Datei oder den Workspace.    |
| `:Trouble telescope`           | Integriert Trouble mit Telescope (falls installiert).                                             |
| `:Trouble telescope_files`     | Zeigt Dateien mit Telescope-Integration.                                                         |
