# Windows File Explorer Keymaps

|           Aktion               |   Shortcut    |
| ------------------------------ | ------------- |
|               F2               |  Umbenennen   |
|          Alt + Enter           | Eigenschaften |
|          Shift + F10           |  Rechtsklick  |
| Ctrl + Shift + C Pfad kopieren |               |
|            Ctrl + C            |   Kopieren    |
|            Ctrl + X            | Ausschneiden  |
|             Delete             |    Löschen    |
|             Enter              |    Öffnen     |

## File/Ordner Kontextmenü

|                     Aktion                     |        Shortcut         |
| ---------------------------------------------- | ----------------------- |
|              Eigenschaften öffnen              |       Alt + Enter       |
|        Kontextmenü (Rechtsklick) öffnen        |       Shift + F10       |
|                   Umbenennen                   |           F2            |
|                    Löschen                     |         Delete          |
|               Dauerhaft löschen                |     Shift + Delete      |
|                    Kopieren                    |        Ctrl + C         |
|                  Ausschneiden                  |        Ctrl + X         |
|                    Einfügen                    |        Ctrl + V         |
|             Neuen Ordner erstellen             |    Ctrl + Shift + N     |
|            Alle Elemente markieren             |        Ctrl + A         |
|           Suche im aktuellen Ordner            |    Ctrl + E oder F3     |
|                Explorer öffnen                 |       Windows + E       |
|                 Aktualisieren                  |           F5            |
|              Eine Ebene nach oben              |  Alt + Pfeil nach oben  |
|                     Zurück                     | Alt + Pfeil nach links  |
|                    Vorwärts                    | Alt + Pfeil nach rechts |
|            Adressleiste fokussieren            |  Alt + D oder Ctrl + L  |
|        Vorschaufenster ein-/ausblenden         |         Alt + P         |
|             Neues Explorer-Fenster             |        Ctrl + N         |
|               Fenster schließen                |        Ctrl + W         |
| Eigenschaften eines ausgewählten Files/Ordners |       Alt + Enter       |

---

## File/Ordner markiert

|      Aktion auf markiertem Element       |                 Shortcut                  |
| ---------------------------------------- | ----------------------------------------- |
|                  Öffnen                  |                   Enter                   |
|                Umbenennen                |                    F2                     |
|              Eigenschaften               |                Alt + Enter                |
|                 Löschen                  |                  Delete                   |
|            Dauerhaft löschen             |              Shift + Delete               |
|                 Kopieren                 |                 Ctrl + C                  |
|        Ausschneiden (Verschieben)        |                 Ctrl + X                  |
|              Pfad kopieren               |             Ctrl + Shift + C              |
|     Kontextmenü öffnen (Rechtsklick)     |                Shift + F10                |
|        Mehrfachauswahl erweitern         |            Shift + Pfeiltasten            |
| Einzelne Elemente zur Auswahl hinzufügen |               Ctrl + Klick                |
|            Bereich auswählen             |               Shift + Klick               |
|              Alle auswählen              |                 Ctrl + A                  |
|             Auswahl aufheben             | Ctrl + Leertaste (bei Tastaturnavigation) |
|   Datei/Ordner in neuem Fenster öffnen   | Ctrl + Enter (nicht überall unterstützt)  |
|            Vorschau anzeigen             |                  Alt + P                  |
