# Fuuzy FInder Plugin Notes

## Telescope File Browser – Default Keymaps

| Modus | Taste           | Aktion                                                          |
| ----- | --------------- | --------------------------------------------------------------- |
| i     | Alt-c           | Datei/Ordner erstellen                                          |
| i     | Shift-Enter     | Aus Prompt erstellen/öffnen                                     |
| i     | Alt-r           | Umbenennen (Mehrfachauswahl möglich)                            |
| i     | Alt-m           | Verschieben                                                     |
| i     | Alt-y           | Kopieren                                                        |
| i     | Alt-d           | Löschen                                                         |
| i     | Ctrl-o          | Öffnen                                                          |
| i     | Ctrl-g          | In Elternverzeichnis wechseln                                   |
| i     | Ctrl-e          | Home-Verzeichnis öffnen                                         |
| i     | Ctrl-w          | Zum aktuellen CWD springen                                      |
| i     | Ctrl-t          | CWD auf aktuelles Verzeichnis setzen                            |
| i     | Ctrl-f          | Zwischen File-/Folder-Browser umschalten                        |
| i     | Ctrl-h          | Versteckte Dateien umschalten                                   |
| i     | Ctrl-s          | „Alles anzeigen/ausblenden“ umschalten                          |
| i     | Backspace       | Bei leerem Prompt: nach oben wechseln; sonst normal             |
| n     | c               | Erstellen                                                       |
| n     | r               | Umbenennen                                                      |
| n     | m               | Verschieben                                                     |
| n     | y               | Kopieren                                                        |
| n     | d               | Löschen                                                         |
| n     | o               | Öffnen                                                          |
| n     | g               | In Elternverzeichnis wechseln                                   |
| n     | e               | Home-Verzeichnis öffnen                                         |
| n     | w               | Zum aktuellen CWD springen                                      |
| n     | t               | CWD auf aktuelles Verzeichnis setzen                            |
| n     | f               | Zwischen File-/Folder-Browser umschalten                        |
| n     | h               | Versteckte Dateien umschalten                                   |
| n     | s               | „Alles anzeigen/ausblenden“ umschalten                          |
| alle  | Tab / Shift-Tab | Auswahl umschalten und zum nächsten/vorherigen Eintrag springen |

## fzf-lua-explorer – Default Keymaps

| Taste  | Aktion                                 |
| ------ | -------------------------------------- |
| Enter  | Datei öffnen / in Ordner wechseln      |
| Ctrl-a | Neue Datei erstellen                   |
| Ctrl-r | Umbenennen (inkl. Konfliktlösung)      |
| Ctrl-x | Ausschneiden (Zwischenablage)          |
| Ctrl-y | Kopieren (Zwischenablage)              |
| Ctrl-v | Einfügen (mit Konfliktlösung)          |
| Ctrl-e | Zwischenablage leeren                  |
| Ctrl-g | Zum Projekt-Root/CWD springen          |
| Ctrl-b | In Elternverzeichnis wechseln          |
| Ctrl-f | Projektweit Ordner suchen und springen |
| Ctrl-s | Vertikaler Split und öffnen            |
| Ctrl-h | Horizontaler Split und öffnen          |
| Tab    | Mehrfachauswahl umschalten             |
| Del    | Löschen                                |
