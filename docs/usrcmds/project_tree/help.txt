INTRODUCTION                                                      *project_tree*

Asynchronous utilities to inspect a project’s structure:
write a file tree, count files, and copy the tree to the clipboard.
Implementation uses a portable shell pipeline (find, sed, wc) and does not
block the UI. GNU-specific options are avoided.

Design goals:
  • Asynchronous and robust via vim.system
  • Clear separation of logic vs. UI notifications
  • Configurable excludes and output paths
  • Linux/macOS; no Windows support

QUICKSTART                                              *project_tree-quickstart*

After setup:
>
  :ProjectTreeGet              " write a tree file for the current :pwd
  :ProjectTreeCopyClipboard    " copy the existing tree file to the clipboard
  :ProjectFilesCount           " print the number of project files
<

==============================================================================
INSTALLATION (LAZY.NVIM)                                 *project_tree-install*

Example for a local module under nvim/usrcmds/project_tree:
>
  {
    dir = vim.fn.stdpath("config") .. "/nvim/usrcmds/project_tree",
    name = "project_tree",
    lazy = true,
    config = function()
      require("usrcmds.project_tree").setup({
        exclude_patterns = { "*/.git/*" },
        outdir = (os.getenv("XDG_STATE_HOME") and (os.getenv("XDG_STATE_HOME") .. "/nvim/project-tree"))
                 or (os.getenv("HOME") .. "/.local/state/nvim/project-tree"),
        outfile_fmt = "%s-tree.txt",
        notify_prefix = "[ProjectTree] ",
        use_system_clipboard = true,
      })
    end,
    cmd = { "ProjectTreeGet", "ProjectTreeCopyClipboard", "ProjectFilesCount" },
  }
<

COMMANDS                                                *project_tree-commands*

*:ProjectTreeGet*                                              :ProjectTreeGet
    Writes a project tree file into the configured output directory.
    Reports the target path and success/failure.

*:ProjectTreeCopyClipboard*                          :ProjectTreeCopyClipboard
    Copies the existing tree file to the system clipboard.
    Primarily uses Neovim’s + register; on failure and if available,
    falls back to xclip.

*:ProjectFilesCount*                                      :ProjectFilesCount
    Counts files using the same pipeline as the tree (respects excludes)
    and prints the resulting number.

Notes:
  • The project is the current :pwd; the project name is the tail directory.
  • The tree file must exist before CopyClipboard can work.

CONFIGURATION                                             *project_tree-config*

Setup:
>
  require("usrcmds.project_tree").setup({ ... })
<

Options and defaults:

  Name                   Type        Default                                   Description
  -----------------------------------------------------------------------------------------
  exclude_patterns       string[]    { "*/.git/*" }                             Shell globs to exclude
  outdir                 string      $XDG_STATE_HOME/nvim/project-tree          Output directory for files
                                       or ~/.local/state/nvim/project-tree
  outfile_fmt            string      "%s-tree.txt"                              File name; %s = project name (tail of :pwd)
  notify_prefix          string      "[ProjectTree] "                           Prefix in returned messages
  use_system_clipboard   boolean     true                                       First use + register, then xclip as fallback

Remarks:
  • The output directory is ensured during setup (mkdir -p semantics).
  • Excludes are applied via: find -not -path "<glob>".

API (LUA)                                                    *project_tree-api*

*project_tree.setup()*
>
  --- @param cfg ProjectTreeConfig|nil
  require("usrcmds.project_tree").setup({
    exclude_patterns = { "*/.git/*", "*/node_modules/*", "*/.venv/*" },
  })
<

*project_tree.write_tree()*
>
  --- @param cb fun(success:boolean, msg:string, outpath:string|nil)
  require("usrcmds.project_tree").write_tree(function(ok, msg, path)
    if ok and path then
      vim.notify(msg, vim.log.levels.INFO)
    else
      vim.notify(msg, vim.log.levels.ERROR)
    end
  end)
<

*project_tree.count_files()*
>
  --- @param cb fun(success:boolean, msg:string, count:integer|nil)
  require("usrcmds.project_tree").count_files(function(ok, msg, n)
    vim.notify(msg, ok and vim.log.levels.INFO or vim.log.levels.ERROR)
  end)
<

*project_tree.copy_tree_to_clipboard()*
>
  --- @param cb fun(success:boolean, msg:string)
  require("usrcmds.project_tree").copy_tree_to_clipboard(function(ok, msg)
    vim.notify(msg, ok and vim.log.levels.INFO or vim.log.levels.ERROR)
  end)
<

BEHAVIOR AND NOTES                                        *project_tree-notes*

  • Project resolution: :pwd defines the root; the project name is
    fnamemodify(:pwd, ":t").
  • Portable pipeline:
      find <cwd> -type f [-not -path "<glob>" ...] -print
        | sed -e "s#^<cwd>/##"
        | sort
    Counting uses “… | wc -l”.
  • Clipboard:
      Primary: setreg("+", <content>)
      Linux fallback: xclip -selection clipboard < <file>
  • UI notifications are performed in the commands; low-level functions
    only return values.

==============================================================================
TROUBLESHOOTING                                     *project_tree-troubleshoot*

  Problem                           Cause/Resolution
  ---------------------------------------------------------------------------
  "tree file does not exist"        Run :ProjectTreeGet first or check outdir/
                                    outfile_fmt.

  "cannot parse count"              sed/wc not available or unexpected output.
                                    Verify tools and PATH.

  No clipboard content              Configure Neovim’s clipboard provider.
                                    Install xclip as fallback (Linux).

  Unexpected files included         Extend exclude_patterns (e.g. node_modules,
                                    dist, .venv, target, .direnv).

  Wrong project name                Check :pwd; outfile_fmt uses the tail of
                                    the working directory.

FAQ                                                         *project_tree-faq*

  Q: Why not use find’s "-printf"?
  A: "-printf" is GNU-specific and not available on macOS by default.
     The combination of -print and sed is portable.

  Q: Can the tree list directories instead of files?
  A: Currently files are listed. A variant with "-type d" is easy to add,
     but intentionally not provided here.

  Q: Can fd/rg be used?
  A: Yes, as an optional enhancement. By default find/sed/wc are used for
     portability.
